2.2 离散型随机变量 ⭐⭐

本节真题考频：14 套真题命中 11 套（79%）。每年选择/填空 1-2 道。
典型出题：Poisson 求 $\lambda$ · $E(e^{aX})$ · 二项近似 Poisson · 几何分布无记忆性 · 求分布律的归一化常数。

一、分布律

定义

$X$ 取离散值 $x_1, x_2, \ldots$，分布律 $p_k = P(X = x_k)$，满足

  • $p_k\geq 0$
  • $\sum_k p_k = 1$

分布函数：$F(x) = \sum_{x_k\leq x}p_k$（阶梯函数）。

二、五大常见离散分布（必记！）

1. 0-1 分布（Bernoulli）

$P(X = 1) = p,\ P(X = 0) = 1-p$，$0 < p < 1$。

$E(X) = p,\quad D(X) = p(1-p)$

这是 Bernoulli 试验的单次结果。

2. 二项分布 $B(n, p)$

$n$ 重 Bernoulli 试验中成功次数：

$$P(X = k) = C_n^k p^k(1-p)^{n-k},\quad k = 0, 1, \ldots, n$$

$E(X) = np,\quad D(X) = np(1-p)$

⭐ 最可能值公式（满分笔记重点）

$X\sim B(n, p)$，最可能值 $k^*$：

  • 若 $(n+1)p$ 是整数：$k^* = (n+1)p$ 或 $(n+1)p-1$（两个最可能值！）
  • 否则：$k^* = \lfloor(n+1)p\rfloor$（单一最大）

这个细节多数教材一笔带过，选择题常埋雷。

题：甲乙比赛 10 局，甲每局胜概率 0.6。求甲胜 6 局以上的概率及最可能甲胜局数。
解

$(n+1)p = 11\times 0.6 = 6.6$，非整数，$k^* = \lfloor 6.6\rfloor = 6$。

$P(X\geq 6) = \sum_{k=6}^{10}C_{10}^k 0.6^k 0.4^{10-k}\approx 0.633$。

3. Poisson 分布 $P(\lambda)$ ⭐

$$P(X = k) = \dfrac{\lambda^k e^{-\lambda}}{k!},\quad k = 0, 1, 2, \ldots,\,\lambda > 0$$

$E(X) = \lambda,\quad D(X) = \lambda$（期望 = 方差！）

描述单位时间/空间内稀有事件发生次数。

⭐ Poisson 极限定理

$n$ 大、$p$ 小、$np = \lambda$ 适中时：

$$C_n^k p^k(1-p)^{n-k}\approx \dfrac{\lambda^k e^{-\lambda}}{k!}$$

实用范围：$n\geq 20$ 且 $p\leq 0.05$。

推导（满分笔记）：

$$\lim_{n\to\infty}C_n^k\left(\dfrac{\lambda}{n}\right)^k\left(1-\dfrac{\lambda}{n}\right)^{n-k} = \dfrac{\lambda^k}{k!}\cdot 1\cdot e^{-\lambda}\cdot 1 = \dfrac{\lambda^k e^{-\lambda}}{k!}$$
题 ★（设备故障）：90 台设备每台故障率 0.01，配 $N$ 工人。求至少需配几人使"故障数 > $N$"的概率 < 0.01。
解

$X\sim B(90, 0.01)\approx P(0.9)$。$P(X\leq 4) = \sum_{k=0}^4\frac{0.9^k e^{-0.9}}{k!}\approx 0.9977$。

$P(X\geq 5) = 1-0.9977 = 0.0023 < 0.01$，所以 $N = 4$ 足够。

4. 几何分布 $G(p)$

首次成功所需试验次数：

$$P(X = k) = p(1-p)^{k-1},\quad k = 1, 2, \ldots$$

$E(X) = 1/p,\quad D(X) = (1-p)/p^2$

⭐ 无记忆性（离散唯一！）
$$P(X > m+n\mid X > m) = P(X > n)$$

"已经等了 $m$ 次没成功，再等 $n$ 次成功的概率与从头等 $n$ 次一样"。

结论：离散分布中唯一具有无记忆性的是几何分布。

5. 超几何分布

$N$ 件含 $M$ 个次品，不放回抽 $n$ 件，次品数 $X$：

$$P(X = k) = \dfrac{C_M^k C_{N-M}^{n-k}}{C_N^n}$$

$E(X) = nM/N$；$n\ll N$ 时近似 $B(n, M/N)$。

6. 帕斯卡（负二项）分布

第 $r$ 次成功所需试验次数：

$$P(X = k) = C_{k-1}^{r-1}p^r(1-p)^{k-r},\quad k = r, r+1, \ldots$$

$E(X) = r/p$。$r = 1$ 时退化为几何分布。

三、分布比较

分布$P(X=k)$$E$$D$实际背景
0-1$p^k(1-p)^{1-k}$$p$$p(1-p)$单次试验
$B(n,p)$$C_n^k p^k(1-p)^{n-k}$$np$$np(1-p)$$n$ 次独立试验成功数
$P(\lambda)$$\lambda^k e^{-\lambda}/k!$$\lambda$$\lambda$稀有事件计数
$G(p)$$p(1-p)^{k-1}$$1/p$$(1-p)/p^2$首次成功时间

四、可加性

  • $B(n_1, p) + B(n_2, p) = B(n_1+n_2, p)$（独立、同 $p$！）
  • $P(\lambda_1) + P(\lambda_2) = P(\lambda_1+\lambda_2)$（独立）
  • 几何分布无可加性，但 $r$ 个独立 $G(p)$ 的和服从负二项 $NB(r, p)$

五、典型例题（LOTUS）

题：$X\sim P(\lambda)$，求 $E(3^X)$。
解
$$E(3^X) = \sum_{k=0}^\infty 3^k\dfrac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda}\sum_{k=0}^\infty\dfrac{(3\lambda)^k}{k!} = e^{-\lambda}\cdot e^{3\lambda} = e^{2\lambda}$$

更一般：$E(e^{aX}) = e^{\lambda(e^a-1)}$ —— 这是 Poisson 分布的矩母函数。

题：$X\sim B(n, p)$，求 $E(e^{3X})$。
解
$$E(e^{3X}) = \sum_{k=0}^n e^{3k}C_n^k p^k(1-p)^{n-k} = (pe^3+1-p)^n$$

二项分布的矩母函数。

六、易错点清单

  • 二项 vs Poisson 适用条件辨析
  • 几何分布"首次成功"次数从 1 开始（不是 0）
  • 负二项 $P(X = k) = C_{k-1}^{r-1}p^r(1-p)^{k-r}$，起始 $k = r$
  • 二项最可能值 $(n+1)p$ 是整数时有两个最可能值
  • $E(X^2) \neq [E(X)]^2$（"平方的期望" vs "期望的平方"）
  • Poisson 期望 = 方差 = $\lambda$
记忆口诀：
  • "0-1 → 二项 → Poisson"（关系链）
  • "$n$ 大 $p$ 小 → Poisson 近似"
  • "几何分布无记忆，离散唯一"
  • "Poisson：$E = D = \lambda$"

七、真题套路 · 二级结论 · 速算技巧

识别分布的速查表

问题特征对应分布
单次试验，成功 / 失败0-1 分布
$n$ 次独立试验，成功次数$B(n,p)$
稀有事件计数，单位时间发生数$P(\lambda)$
首次成功时间 / 次数$G(p)$
第 $r$ 次成功时间负二项 / Pascal
$N$ 中含 $M$ 次品，不放回抽 $n$超几何

必背二级结论

  1. $E$ 与 $D$ 总表：0-1 → $p, p(1-p)$；$B(n,p)$ → $np, np(1-p)$；$P(\lambda)$ → $\lambda, \lambda$；$G(p)$ → $1/p, (1-p)/p^2$
  2. 二项最可能值：$(n+1)p$ 是整数时双峰（$k^*$ 与 $k^*-1$）；非整数时 $k^* = \lfloor(n+1)p\rfloor$
  3. Poisson 近似：$n\geq 20, p\leq 0.05$ 时 $B(n,p)\approx P(np)$
  4. 几何无记忆性：$P(X>m+n\mid X>m) = P(X>n)$（离散唯一！）
  5. $E(e^{aX})$ 矩母函数：
    • $X\sim B(n,p)$：$(pe^a+1-p)^n$
    • $X\sim P(\lambda)$：$e^{\lambda(e^a-1)}$
    • $X\sim G(p)$：$pe^a/(1-(1-p)e^a)$
  6. Poisson 拆分：$X\sim P(\lambda)$，每次试验独立按 $p$ 拆 → 拆出的 $X_1\sim P(\lambda p)$
  7. 可加性：$B(n_1,p)+B(n_2,p)=B(n_1+n_2,p)$；$P(\lambda_1)+P(\lambda_2) = P(\lambda_1+\lambda_2)$
  8. $D = E(X^2)-(EX)^2$，$E(X(X-1))$ 拆分技巧

速算与解题技巧

  1. 识别分布 → 直接套 $E, D$，不用算积分/求和
  2. Poisson 求 $E(e^{aX})$：直接套 $e^{\lambda(e^a-1)}$
  3. 大 $n$ 二项近似选 Poisson 还是正态：$p$ 小用 Poisson，$p$ 适中用正态
  4. 泊松流的间隔时间：服从 $E(\lambda)$（链接到下一节）
  5. 查表速算：教材附表给 Poisson 分布表，按 $\lambda$ 和 $k$ 查

常错"小坑"清单

  • 几何分布从 1 开始（不是 0）
  • $(n+1)p$ 整数时双峰—— 选择题常考
  • 二项 vs Poisson 适用：$p$ 不小时不能用 Poisson 近似
  • $E(X^2) = D(X)+(EX)^2$—— 不要忘第二项
  • Poisson 期望 = 方差（独有特性）
