1.2 随机事件的概率 ⭐

本节真题考频：14 套真题命中 6 套，多为选择/填空。古典 / 几何概型每年至少 1 题。
典型出题：摸球 · 配对 · 几何概型（点在区域）· 容斥应用 · 抽签公平性。

一、频率与概率的关系

频率 → 概率

事件 $A$ 在 $n$ 次试验中发生 $m$ 次，频率 $f_n(A) = m/n$。大量重复时频率稳定于某常数 $p$，记 $P(A) = p$。

这是概率的"统计定义"。

⭐ Kolmogorov 概率公理（1933）

$P$ 是 $\sigma$-代数到 $[0, 1]$ 的函数，满足：

  1. 非负性：$P(A)\geq 0$
  2. 规范性：$P(\Omega) = 1$
  3. 可列可加性：$A_i$ 两两互斥 $\Rightarrow P\!\left(\bigcup_{i=1}^\infty A_i\right) = \sum_{i=1}^\infty P(A_i)$

二、概率的性质（由公理推出）

  • $P(\varnothing) = 0$
  • $P(\bar A) = 1-P(A)$
  • $A\subset B\Rightarrow P(A)\leq P(B)$，且 $P(B-A) = P(B)-P(A)$
  • 一般差：$P(B-A) = P(B)-P(AB)$
  • 有限可加性：$A_i$ 两两互斥 $\Rightarrow P(\bigcup A_i) = \sum P(A_i)$
  • $0\leq P(A)\leq 1$
⭐ 加法公式与容斥
$$P(A\cup B) = P(A)+P(B)-P(AB)$$ $$P(A\cup B\cup C) = P(A)+P(B)+P(C)-P(AB)-P(AC)-P(BC)+P(ABC)$$

一般 $n$ 事件容斥：

$$P\!\left(\bigcup_{i=1}^n A_i\right) = \sum_i P(A_i)-\sum_{i
速算技巧：见到"至少一个发生"优先用对立 $1-P(\bar A_1\cdots\bar A_n)$，比展开容斥简单。独立时简化为 $1-\prod(1-P(A_i))$。

三、古典概型

古典概型（等可能事件）

条件：① 样本点有限；② 每个样本点等可能。则

$$P(A) = \dfrac{A\text{ 的样本点数}}{\Omega\text{ 的样本点数}} = \dfrac{M}{N}$$

常用计数公式

  • 有放回排列：从 $n$ 中取 $r$，$n^r$
  • 无放回排列：$A_n^r = \dfrac{n!}{(n-r)!}$
  • 组合：$C_n^r = \dfrac{n!}{r!(n-r)!}$
题型 ★（生日问题）：$n$ 人，每人生日独立等可能取 365 天之一。求 "$n$ 人生日各不相同" 的概率。
解
$$P = \dfrac{A_{365}^n}{365^n} = \dfrac{365\cdot 364\cdots(365-n+1)}{365^n}$$

对立："至少两人生日相同" $= 1-P$。$n = 23$ 时该概率 $\approx 0.507 > 1/2$，反直觉！

题型 ★★（抽签公平性，多年真题原型）：袋中 $a$ 个白球 $b$ 个黑球，无放回连续取 $n$ 个。求第 $k$ 次取到白球的概率。
解

$P = \dfrac{a}{a+b}$，与 $k$ 无关。可由古典概型（考虑全排列）或递推证明。

结论："不放回抽签每个位置等公平"——必背！

题型（配对问题，hat-matching）：$n$ 个球编号放入 $n$ 个盒子（每盒一球，随机）。求"至少一个配对"的概率。
解

记 $A_i$ = "盒 $i$ 配对"。用容斥：

$$P\!\left(\bigcup A_i\right) = \sum_{k=1}^n\dfrac{(-1)^{k-1}}{k!}\xrightarrow{n\to\infty}1-\dfrac{1}{e}\approx 0.632$$

结论：配对数期望 $E = 1$，方差 $D = 1$，与 $n$ 无关！这是 hat-matching 的标志结论。

四、几何概型

几何概型

$\Omega\subset\mathbb R^n$ 是几何区域（有限测度），$\omega$ 落入 $\Omega$ 中每点等可能。则

$$P(A) = \dfrac{\mu(A)}{\mu(\Omega)}$$

$\mu$ 是适当测度：长度、面积、体积。

题（约会问题）：甲乙约 12:00-13:00 在某处见面，先到者等 20 分钟。求二人能见面的概率。
解

设甲到达 $x$、乙 $y$（分钟）。$\Omega = [0,60]^2$，面积 3600。

"能见面" = $\{|x-y|\leq 20\}$，是 $\Omega$ 减去两个直角三角形（每个面积 800）。

$$P = \dfrac{3600-1600}{3600} = \dfrac{5}{9}$$
题（Buffon 投针）：平面画平行线间距 $a$，针长 $l
解

针中点到最近线距离 $x\in[0, a/2]$，针与线夹角 $\theta\in[0, \pi]$。相交 $\Leftrightarrow x\leq\dfrac{l}{2}\sin\theta$。

$$P = \dfrac{\int_0^\pi(l\sin\theta/2)\dd\theta}{\dfrac{a}{2}\cdot\pi} = \dfrac{2l}{a\pi}$$

应用：投针 $n$ 次命中 $m$ 次 → $\pi\approx 2ln/(am)$，可估算 $\pi$。历史上 Lazzerini 投 3408 次得 $\pi\approx 3.1415929$。

五、易错点 & 必背结论

  • 古典概型必须 "有限 + 等可能"，缺一不可
  • 放回 vs 不放回结果不同
  • 几何概型不同设法可能给不同答案（Bertrand 悖论），按题意自然设定
  • 容斥公式正负号易错，$P(ABC)$ 是 +
  • "至少一个发生" 直接展开常算错，用对立简单
本节 5 条必背结论：
  1. $P(\bar A) = 1-P(A)$（最常用）
  2. $P(B-A) = P(B)-P(AB)$
  3. 加法公式 $P(A\cup B) = P(A)+P(B)-P(AB)$
  4. 三事件容斥（带 $+P(ABC)$）
  5. 抽签公平性：第 $k$ 次抽到的概率 $= a/(a+b)$ 与 $k$ 无关

六、真题套路 · 二级结论 · 速算技巧

题型决策树

  • 有限等可能 → 古典概型：算 $M/N$
  • 区域中均匀 → 几何概型：算 $\mu(A)/\mu(\Omega)$
  • "至少一个发生" → 用对立：$1-P(\bar A_1\cdots\bar A_n)$
  • 多事件交并 → 容斥

必背二级结论

  1. $P(\bar A) = 1-P(A)$（最常用）
  2. $P(B-A) = P(B)-P(AB)$（一般差）
  3. 加法公式：$P(A\cup B) = P(A)+P(B)-P(AB)$
  4. 三事件容斥带 $+P(ABC)$
  5. 抽签公平性：$a$ 难签 + $b$ 易签，每位 $P($难$) = a/(a+b)$
  6. 生日问题：$n=23$ 时 $P($至少两人同生日$)\approx 0.507>1/2$
  7. Buffon 投针：$P = 2l/(a\pi)$（$l$ = 针长，$a$ = 线距）
  8. 配对问题：$P($至少一配对$)\to 1-1/e\approx 0.632$
  9. 独立时 "至少一个发生"：$1-\prod(1-P(A_i))$

速算与解题技巧

  1. "至少 / 至多" 立刻用对立，比展开容斥快
  2. 排列 vs 组合：考虑顺序 → 用 $A_n^r$；不考虑顺序 → 用 $C_n^r$
  3. 不放回的等价处理：把它视为对所有可能全排列的等可能选择
  4. 几何概型样本空间设法：按"自然"参数（位置 $x$、角度 $\theta$ 等）设定
  5. 容斥前 3 项预算：$\sum P(A_i),\,\sum P(A_iA_j),\,\sum P(A_iA_jA_k)$，符号 $+, -, +$

常错"小坑"清单

  • 古典概型必须 有限 + 等可能
  • 放回 vs 不放回结果不同
  • 容斥符号易错（$P(ABC)$ 是 $+$）
  • 几何概型不同设法可能给不同答案（Bertrand 悖论）
  • "至少一个" 直接展开容斥常算错
