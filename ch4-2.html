4.2 方差 ⭐⭐

本节真题考频：每年大题中频繁作为工具。结合期望/协方差出题。
典型出题：$D(X-Y)$ 独立时的符号 · $D(\bar X) = \sigma^2/n$ · $E(\bar X^2) = \sigma^2/n+\mu^2$（连考 3 套！）。

一、方差与标准差

$$D(X) = E[(X-EX)^2] = E(X^2)-[E(X)]^2$$

标准差 $\sigma_X = \sqrt{D(X)}$，与 $X$ 同量纲。

标准化随机变量
$$X^* = \dfrac{X-EX}{\sigma_X},\quad E(X^*) = 0,\;D(X^*) = 1$$
$D(X) = 0\Rightarrow X$ 几乎处处等于 $E(X)$（即 $P(X=EX) = 1$）。

二、方差的性质（必背）

  1. $D(C) = 0$（常数无方差）
  2. $D(CX) = C^2 D(X)$（注意 $C^2$，不是 $|C|$）
  3. $D(X+C) = D(X)$（平移不改变方差）
  4. $D(X\pm Y) = D(X)+D(Y)\pm 2\Cov(X, Y)$
  5. $X, Y$ 独立 $\Rightarrow D(X+Y) = D(X)+D(Y)$；$D(X-Y) = D(X)+D(Y)$ （同号！）
  6. 多个独立：$D(\sum a_iX_i) = \sum a_i^2 D(X_i)$
易错：$D(X-Y)\neq D(X)-D(Y)$！独立时仍是 $D(X)+D(Y)$，方差永远非负，加减号都变加。

三、七大分布方差总表（必背！）

分布$E(X)$$D(X)$
0-1$p$$p(1-p)$
$B(n, p)$$np$$np(1-p)$
$P(\lambda)$$\lambda$$\lambda$（=$E$！）
$G(p)$$1/p$$(1-p)/p^2$
$U(a, b)$$(a+b)/2$$(b-a)^2/12$
$E(\lambda)$$1/\lambda$$1/\lambda^2$
$N(\mu, \sigma^2)$$\mu$$\sigma^2$
$\chi^2(n)$$n$$2n$

四、典型例题

题 ★（独立正态相加减）：$X\sim N(1, 0.5),\,Y\sim N(0, 0.5)$ 独立，求 $E|X-Y|$。
解

$Z = X-Y\sim N(1, 1)$。令 $W = Z-1\sim N(0, 1)$，$|Z| = |W+1|$。

$E|Z| = \int(z+1)\varphi(z)\dd z$（分段）= ... ≈ 1.16（具体计算见教材）。

题 ★★★ 配对数方差（hat-matching）：$n$ 个球编号放入 $n$ 个盒（一一对应），配对数 $X$。求 $E(X), D(X)$。
解

$X = \sum X_i$，$X_i$ 是"盒 $i$ 配对"的示性。

$E(X_i) = 1/n$，$E(X) = 1$。

$E(X_iX_j) = 1/(n(n-1))$（$i\neq j$）。

$E(X^2) = n\cdot\frac{1}{n}+n(n-1)\cdot\frac{1}{n(n-1)} = 1+1 = 2$。

$D(X) = E(X^2)-[E(X)]^2 = 2-1 = 1$。$E = D = 1$，与 $n$ 无关！

题（满分笔记重点公式）：$X_1, \ldots, X_n$ i.i.d. $\sim$ 任意分布，$E(X) = \mu, D(X) = \sigma^2$。求 $E(\bar X^2)$。
解
$$E(\bar X^2) = D(\bar X)+(E(\bar X))^2 = \dfrac{\sigma^2}{n}+\mu^2$$

这是 23-24 系列连考 3 套的关键公式！ 用于判断 $\bar X^2$ 是否为 $\mu^2$ 的无偏估计。

真题原型 ★★（公式法求方差 · 连续型）：$X\sim U(0,2)$（即 $f(x)=\frac12,\,0
解

用 $D=E(X^2)-(EX)^2$，避免定义法。

$E(X)=1$，$E(X^2)=\int_0^2 x^2\cdot\tfrac12\dd x=\tfrac12\cdot\tfrac{8}{3}=\tfrac43$。故 $D(X)=\tfrac43-1=\tfrac13$，与公式 $\frac{(b-a)^2}{12}=\frac{4}{12}=\frac13$ 吻合 ✓。

$E(X^4)=\int_0^2 x^4\cdot\tfrac12\dd x=\tfrac12\cdot\tfrac{32}{5}=\tfrac{16}{5}$。故 $D(X^2)=E(X^4)-[E(X^2)]^2=\tfrac{16}{5}-\tfrac{16}{9}=\tfrac{144-80}{45}=\tfrac{64}{45}$。

套路：求 $g(X)$ 的方差永远 $D(g)=E(g^2)-(E g)^2$，分别按 LOTUS 算两个矩。

五、易错点清单

  • $D(X-Y) = D(X)+D(Y)$ 独立时（同号！），不是 $D(X)-D(Y)$
  • $D(aX) = a^2 D(X)$（不是 $|a|D(X)$ 或 $aD(X)$）
  • $E(X^2)\neq[E(X)]^2$（永远）
  • 用 $D = E(X^2)-[E(X)]^2$ 通常比定义法简洁
  • 独立性条件遗漏 → 不能用 $D(X+Y) = D(X)+D(Y)$
  • $D(\bar X) = \sigma^2/n$（除以 $n$，不是 $\sqrt n$）
  • 求 $D(g(X))$ 别套错：必须 $E(g^2)-(Eg)^2$，不能写成 $g(D(X))$ 或对 $D(X)$ 做函数变换
  • $\bar X$ 与 $S^2$ 的"除数"易混：$\bar X$ 除 $n$、样本方差 $S^2$ 除 $n-1$（才无偏），别写反
⭐ 必背速查（方差）
  • 核心：$D(X)=E(X^2)-[E(X)]^2$（计算首选）；$\sigma_X=\sqrt{D(X)}$
  • 性质：$D(C)=0$；$D(CX)=C^2D(X)$；$D(X+C)=D(X)$
  • 独立同号：$X\perp Y\Rightarrow D(X\pm Y)=D(X)+D(Y)$（加减都变加！）
  • 一般：$D(X\pm Y)=D(X)+D(Y)\pm2\Cov(X,Y)$；$D(\sum a_iX_i)=\sum a_i^2D(X_i)$（独立）
  • 七大分布 $D$：0-1→$p(1-p)$；$B(n,p)$→$np(1-p)$；$P(\lambda)$→$\lambda$；$G(p)$→$\frac{1-p}{p^2}$；$U(a,b)$→$\frac{(b-a)^2}{12}$；$E(\lambda)$→$1/\lambda^2$；$N(\mu,\sigma^2)$→$\sigma^2$；$\chi^2(n)$→$2n$
  • 样本：$D(\bar X)=\sigma^2/n$；$E(\bar X^2)=\sigma^2/n+\mu^2$；$E(S^2)=\sigma^2$（无偏）
  • hat-matching：配对数 $D(X)=1$（与 $n$ 无关）
记忆口诀：
  • "$D = E(X^2) - (EX)^2$"（计算神器）
  • "独立 $D(X\pm Y) = D(X) + D(Y)$ 永远加"
  • "$D(\bar X) = \sigma^2/n$，除以 $n$"
  • "$E(\bar X^2) = \sigma^2/n + \mu^2$，连考 3 套必背"

六、真题套路 · 二级结论 · 速算技巧

计算 $D(X)$ 的两条路径

  1. 定义法：$D(X) = E[(X-EX)^2]$
  2. 公式法（更常用）：$D(X) = E(X^2)-(E(X))^2$

必背二级结论

  1. 七大分布方差（必背）：0-1→$p(1-p)$；$B(n,p)$→$np(1-p)$；$P(\lambda)$→$\lambda$；$G(p)$→$(1-p)/p^2$；$U(a,b)$→$(b-a)^2/12$；$E(\lambda)$→$1/\lambda^2$；$N(\mu,\sigma^2)$→$\sigma^2$；$\chi^2(n)$→$2n$
  2. $D(\bar X) = \sigma^2/n$（任意分布）
  3. $E(\bar X^2) = \sigma^2/n + \mu^2$（连考 3 套关键公式！）
  4. $E(S^2) = \sigma^2$（任意分布无偏）
  5. 性质：$D(C) = 0$；$D(CX) = C^2 D(X)$；$D(X+C) = D(X)$
  6. 独立加和：$D(X+Y) = D(X)+D(Y)$；$D(X-Y) = D(X)+D(Y)$（同号！）
  7. 一般加和：$D(X\pm Y) = D(X)+D(Y)\pm 2\Cov(X,Y)$
  8. hat-matching：$E(X) = D(X) = 1$，与 $n$ 无关
  9. $D(\sum a_iX_i) = \sum a_i^2 D(X_i)$（独立时）
  10. $D(X) = 0\Rightarrow X = E(X)$ 几乎必然

速算与解题技巧

  1. 识别分布 → 直接套 $D$
  2. 用 $D = E(X^2)-(EX)^2$ 而非定义法，通常更简洁
  3. 独立加减都是 $D(X)+D(Y)$（同号！）
  4. $D(\bar X)$ 永远是 $\sigma^2/n$，CLT、估计都用
  5. $X^2\sim\sigma^2\chi^2(1)$（$X\sim N(0,\sigma^2)$），所以 $D(X^2) = 2\sigma^4$
  6. $E(\bar X^2)$ 拆分：永远是 $D(\bar X) + (E(\bar X))^2 = \sigma^2/n + \mu^2$

常错"小坑"清单

  • $D(X-Y) = D(X)+D(Y)$ 独立时（同号！）—— 不是减号
  • $D(aX) = a^2 D(X)$—— 不是 $|a|D(X)$
  • $E(X^2)\neq[E(X)]^2$
  • $D(\bar X)$ 分母是 $n$ 不是 $\sqrt n$
  • $E(\bar X^2) = \sigma^2/n + \mu^2$ 漏 $\mu^2$
  • 独立条件遗漏：非独立时要加 $2\Cov$
