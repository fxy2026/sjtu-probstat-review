8.1 假设检验 ⭐⭐⭐

本节真题考频：14 套真题命中 13 套（93%）。每年大题第 19 题（10 分，压轴）。
近 3 年趋势：从单一拒绝域法 → P 值法 + 经典法并列（22-23 起）。23-24-2 第 19 题考的就是 P 值法+经典法双问。
典型出题：23-24-2 车轴直径 · 22-23-2 笔记本续航 · 20-21-2 脉搏 · 17-18-2 光纤。

一、基本概念

原假设 $H_0$ vs 备择假设 $H_1$
  • $H_0$：默认成立，需数据"反对"才能拒绝。"保护"的假设
  • $H_1$：与 $H_0$ 对立的假设
  • 双侧：$H_1:\theta\neq\theta_0$
  • 左侧：$H_1:\theta < \theta_0$
  • 右侧：$H_1:\theta > \theta_0$
两类错误
$H_0$ 真$H_0$ 假
接受 $H_0$正确第二类错误（弃假取真，记 $\beta$）
拒绝 $H_0$第一类错误（弃真取假，记 $\alpha$）正确（功效 $1-\beta$）

$\alpha$ = 显著性水平 = 拒真概率。一般 $\alpha = 0.05$ 或 $0.01$。

核心原则：控制第一类错误的概率 $\leq\alpha$。"宁可错过，不可冤枉"——把保护的结论作为 $H_0$。

二、两种检验流程

2.1 经典临界值法（拒绝域法）

⭐ 标准五步
  1. 提出 $H_0, H_1$
  2. 选择检验统计量（含 $\theta_0$，分布在 $H_0$ 下已知）
  3. 构造拒绝域 $C$，使 $P(T\in C\mid H_0) = \alpha$
  4. 由样本算统计量观测值 $T_{\text{obs}}$
  5. 判定：$T_{\text{obs}}\in C$ → 拒绝 $H_0$；否则不拒绝

2.2 P 值法（近年高频！）

P 值定义：在 $H_0$ 真时，得到"比观察样本更极端"统计量的概率。

规则：

  • $P < \alpha$ → 拒绝 $H_0$
  • $P\geq\alpha$ → 不拒绝 $H_0$

P 值算法（按 $H_1$ 方向）：

  • 双侧：$P = 2P(|T| > |T_{\text{obs}}|)$（或两个单侧概率的较小者 × 2）
  • 右侧：$P = P(T > T_{\text{obs}})$
  • 左侧：$P = P(T < T_{\text{obs}})$
两法关系：在相同 $\alpha$ 下二者完全等价，只是操作顺序不同。P 值给"反对 $H_0$ 的强度"的连续度量。

三、正态总体常用检验（必背！）

3.1 单正态总体 $\mu$ 的检验

U 检验（$\sigma$ 已知）：$U = \dfrac{\bar X-\mu_0}{\sigma/\sqrt n}\sim N(0, 1)$ 在 $H_0:\mu=\mu_0$ 下。

$H_1$拒绝域
$\mu\neq\mu_0$$|U|>u_{\alpha/2}$
$\mu<\mu_0$$U<-u_\alpha$
$\mu>\mu_0$$U>u_\alpha$

t 检验（$\sigma$ 未知）：$T = \dfrac{\bar X-\mu_0}{S/\sqrt n}\sim t(n-1)$。

拒绝域同上，把 $u_\alpha$ 换成 $t_\alpha(n-1)$。

3.2 单正态总体 $\sigma^2$ 的检验

$\chi^2$ 检验（$\mu$ 未知）：$\chi^2 = \dfrac{(n-1)S^2}{\sigma_0^2}\sim\chi^2(n-1)$。

$H_1$拒绝域
$\sigma^2\neq\sigma_0^2$$\chi^2<\chi^2_{1-\alpha/2}(n-1)$ 或 $\chi^2>\chi^2_{\alpha/2}(n-1)$
$\sigma^2<\sigma_0^2$$\chi^2<\chi^2_{1-\alpha}(n-1)$
$\sigma^2>\sigma_0^2$$\chi^2>\chi^2_\alpha(n-1)$

$\chi^2$ 不对称：双侧拒绝域两个端点不互为相反数。

3.3 两个正态总体的检验

$\mu_1 = \mu_2$（$\sigma_1, \sigma_2$ 已知）：$U = \dfrac{\bar X-\bar Y}{\sqrt{\sigma_1^2/n_1+\sigma_2^2/n_2}}\sim N(0, 1)$

$\mu_1 = \mu_2$（$\sigma$ 均未知但相等）：用合并方差 $S_w$，$T = \dfrac{\bar X-\bar Y}{S_w\sqrt{1/n_1+1/n_2}}\sim t(n_1+n_2-2)$

$\sigma_1^2 = \sigma_2^2$：$F = S_1^2/S_2^2\sim F(n_1-1, n_2-1)$

四、典型真题完整解答

题 ★★★★★ 23-24-2 第 19 题（车轴直径，P 值 + 经典法双问，10 分）：车轴直径 $X\sim N(\mu, \sigma^2)$，要求均值 4.0、方差不超过 0.1。25 件样本（频数表给出）算得 $\bar x = 4.02,\,s^2 = 0.105$。
  1. 用 P 值法检验 $H_0:\mu = 4.0$ vs $H_1:\mu\neq 4.0$，$\alpha = 0.05$。
  2. 用经典拒绝域法检验 $H_0:\sigma^2\leq 0.1$ vs $H_1:\sigma^2 > 0.1$，$\alpha = 0.05$。
解（满分模板）

(1) μ 的 t 检验（P 值法）：

$T = \dfrac{\bar x-4}{s/\sqrt{25}} = \dfrac{0.02}{\sqrt{0.105}/5} = \dfrac{0.02}{0.0648}\approx 0.309$

双侧 P 值 $= 2P(|T(24)|>0.309)$。查表 $t_{0.05}(24)=1.711$，$0.309\ll 1.711$，所以 P 值 $\gg 0.10>0.05$。不拒绝 $H_0$。

(2) σ² 的 $\chi^2$ 检验（经典法，单侧）：

$\chi^2 = \dfrac{24\cdot 0.105}{0.1} = 25.2$

拒绝域 $\chi^2 > \chi^2_{0.05}(24) = 36.415$。$25.2 < 36.415$，不拒绝 $H_0$（方差未显著超过 0.1）。

结论：在 5% 显著性水平下，认为车轴生产符合规格要求。

题 ★★★（标准 t 检验）：电池寿命 $\sim N(\mu, \sigma^2)$。$n = 16,\,\bar x = 6.2,\,s = 0.5$，检验 $H_0:\mu = 6.5$ 双侧，$\alpha = 0.05$。
解

$T = \dfrac{6.2-6.5}{0.5/\sqrt{16}} = \dfrac{-0.3}{0.125} = -2.4$

查表 $t_{0.025}(15) = 2.131$。$|T| = 2.4 > 2.131$ → 拒绝 $H_0$。

结论：在 5% 显著性水平下，认为电池实际寿命与 6.5 有显著差异。

题（单侧检验）：某产品要求次品率 $p\leq 0.05$。100 件样本中有 8 件次品。检验是否合格，$\alpha = 0.05$。
解

$H_0:p\leq 0.05$ vs $H_1:p > 0.05$（单侧）。用 CLT 近似：$\hat p = 0.08$，

$U = \dfrac{0.08-0.05}{\sqrt{0.05\cdot 0.95/100}} = \dfrac{0.03}{0.0218}\approx 1.376$

查 $u_{0.05} = 1.645$。$U = 1.376 < 1.645$ → 不拒绝 $H_0$。次品率未显著超标。

五、非参数检验：Pearson $\chi^2$ 拟合优度（满分笔记）

样本空间分 $k$ 个互斥事件 $A_1, \ldots, A_k$，理论概率 $p_i$，实际频数 $n_i$：

$$\chi^2 = \sum_{i=1}^k\dfrac{(n_i-np_i)^2}{np_i}\sim\chi^2(k-1-r)$$

$r$ 为已估计的参数个数。常用于"数据是否来自某分布"检验。

六、易错点清单

  • 单侧 vs 双侧：双侧用 $\alpha/2$，单侧用 $\alpha$（分位数）
  • $\chi^2$ 双侧拒绝域不对称：上下分位数分别查 $\chi^2_{\alpha/2}$ 和 $\chi^2_{1-\alpha/2}$
  • P 值小 = 拒绝 $H_0$，不是"大"
  • P 值的"极端"方向按 $H_1$：右侧检验 $P=P(T\geq T_{\text{obs}})$，单侧
  • $\sigma$ 未知用 $t$，已知用 $u$：题目要看清楚
  • "$\sigma^2$ 不超过 0.05" → 单侧 $H_0:\sigma^2\leq 0.05$，拒绝域 $\chi^2 > \chi^2_\alpha(n-1)$
  • 结论用语："拒绝 $H_0$" 或 "无足够证据拒绝 $H_0$"（不说"接受"更严谨）
  • 样本均值与样本方差区分：检验 $\mu$ 用 $\bar X$ 中心化；检验 $\sigma^2$ 用 $S^2$
记忆口诀：
  • "双侧 $\alpha/2$，单侧 $\alpha$"
  • "$\sigma$ 已知 U，$\sigma$ 未知 t，方差检验 $\chi^2$"
  • "P 值小，拒原假；P 值大，留原假"
  • "保护谁，谁就是 $H_0$"

必背二级结论

  1. P 值 = 在 $H_0$ 真时，得到比观察更极端统计量的概率
  2. P 值小于 $\alpha$ 拒绝 $H_0$；P 值大于 $\alpha$ 不拒绝
  3. P 值法 = 拒绝域法，结论一致
  4. "保护谁谁就是 $H_0$"：原假设是想保护的结论
  5. 第一类错误率 $\alpha$ = 弃真；第二类 $\beta$ = 取假
  6. 双侧用 $\alpha/2$，单侧用 $\alpha$
  7. $\chi^2$ 双侧拒绝域不对称：上下分位数分开查
  8. $\sigma^2$ "不超过 $\sigma_0^2$" → 单侧 $H_0:\sigma^2\leq\sigma_0^2$，拒绝域 $\chi^2>\chi^2_\alpha$
  9. 合并方差自由度：$n_1+n_2-2$
  10. 双侧 P 值算法：$P = 2P(|T|>|T_{\text{obs}}|)$（对称分布）
  11. 近似 P 值与查表关系：若 $|T_{\text{obs}}| 2α；若 $>t_{\alpha/2}$，则 P < α

速算与解题技巧

  1. $\sigma$ 已知 → U；$\sigma$ 未知 → t
  2. 方差检验 → $\chi^2$（不对称！）
  3. 两正态比较：均值用 t（同方差时）；方差用 F
  4. 题目"不少于 / 不超过" → 单侧检验
  5. "显著差异" → 双侧；"显著大于" → 右单侧；"显著小于" → 左单侧
  6. 查表 $t_{0.025}(n-1)$ 双侧 5%；$t_{0.05}(n-1)$ 单侧 5%
  7. $\bar x, s^2$ 算出来后：直接代入对应统计量公式

常错"小坑"清单

  • 单侧 vs 双侧分位数：双侧用 $\alpha/2$，单侧用 $\alpha$
  • $\chi^2$ 双侧不对称：要查两次分位数
  • P 值小 = 拒绝 $H_0$，不是"大"
  • P 值"极端"方向按 $H_1$：右单侧 $P = P(T\geq T_{\text{obs}})$
  • $\sigma$ 已知/未知用对统计量
  • "$\sigma^2$ 不超过 $\sigma_0^2$" 是单侧 $H_0$
  • 结论用词：用"拒绝 $H_0$"或"无足够证据拒绝 $H_0$"（不说"接受"更严谨）
  • 检验 $\mu$ 用 $\bar X$ 中心化；检验 $\sigma^2$ 用 $S^2$，不要混淆
