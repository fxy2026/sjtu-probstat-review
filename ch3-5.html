3.5 多维随机变量函数的分布 ⭐⭐⭐

本节真题考频：14 套命中 13 套（93%）。每年大题第 15 题（9 分）的核心。
典型出题：$Z=X+Y$ 卷积 · $\max/\min$ 极值 · $X^2+Y^2$（导出 $\chi^2(2)$）· 周长 $Z=2(X+Y)$ 的密度。

一、分布函数法（万能）

$Z = g(X, Y)$，分布函数

$$F_Z(z) = P(g(X, Y)\leq z) = \iint_{g(x,y)\leq z} f(x, y)\dd x\,\dd y$$

对 $z$ 求导得 $f_Z$。

二、和的分布：卷积公式 ⭐

⭐ 连续型卷积公式

$Z = X+Y$，密度

$$f_Z(z) = \int_{-\infty}^{+\infty}f(x, z-x)\dd x = \int_{-\infty}^{+\infty}f(z-y, y)\dd y$$

独立时简化为卷积：

$$f_Z(z) = \int_{-\infty}^{+\infty}f_X(x)f_Y(z-x)\dd x$$
离散型卷积
$$P(Z = r) = \sum_k P(X = k)P(Y = r-k)$$
分段技巧：画 $f_X(x)\cdot f_Y(z-x)$ 同时非零的 $(x, z)$ 区域，按 $z$ 分段确定积分上下限。这是卷积题最容易出错的地方。
题 ★★★（三角分布）：$X, Y\sim U(0, 1)$ 独立，求 $Z = X+Y$ 的密度。
解

$f_X(x) = 1,\ 0 < x < 1$，$f_Y(z-x) = 1$ 当 $0 < z-x < 1$ 即 $z-1 < x < z$。

两个非零范围交集：$\max(0, z-1) < x < \min(1, z)$。分段：

  • $0\leq z\leq 1$：$x\in(0, z)$，$f_Z(z) = z$
  • $1 < z\leq 2$：$x\in(z-1, 1)$，$f_Z(z) = 2-z$
  • 否则 $f_Z = 0$

三角分布，对称于 $z = 1$。

题（独立正态相加）：$X\sim N(\mu_1, \sigma_1^2),\ Y\sim N(\mu_2, \sigma_2^2)$ 独立，求 $X+Y$ 分布。
解

直接用可加性：$X+Y\sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)$。无需做卷积！

更一般：$aX+bY\sim N(a\mu_1+b\mu_2, a^2\sigma_1^2+b^2\sigma_2^2)$。

周长陷阱（多年真题）：若题问 $Z = 2(X+Y)$ 的密度，先用卷积求 $W = X+Y$ 密度，再用线性变换公式 $f_Z(z) = \dfrac{1}{2}f_W(z/2)$。记得乘 1/2！

三、可加性分布表（必背！）

分布条件结论
二项 $B(n,p)$独立、同 $p$$B(n_1, p) + B(n_2, p) = B(n_1+n_2, p)$
Poisson $P(\lambda)$独立$P(\lambda_1) + P(\lambda_2) = P(\lambda_1+\lambda_2)$
正态 $N(\mu, \sigma^2)$独立$\sum a_iX_i\sim N(\sum a_i\mu_i, \sum a_i^2\sigma_i^2)$
卡方 $\chi^2(n)$独立$\chi^2(n_1)+\chi^2(n_2) = \chi^2(n_1+n_2)$
Gamma $\Gamma(\alpha,\beta)$独立、同 $\beta$$\Gamma(\alpha_1, \beta)+\Gamma(\alpha_2, \beta) = \Gamma(\alpha_1+\alpha_2, \beta)$
指数分布不具有可加性（除非视为 $\Gamma(1, \lambda)$，则 $n$ 个独立 $E(\lambda)$ 的和 $\sim\Gamma(n, \lambda)$）。

四、极值分布

⭐ 独立 $X_1, \ldots, X_n$ 的 max / min

最大值 $M = \max\{X_i\}$：

$$F_M(z) = P(\max X_i\leq z) = P(\text{每个 }X_i\leq z) = \prod_{i=1}^n F_{X_i}(z)$$

最小值 $N = \min\{X_i\}$：

$$F_N(z) = 1-P(\min X_i > z) = 1-\prod_{i=1}^n[1-F_{X_i}(z)]$$

i.i.d. 同分布：$F_M(z) = F(z)^n$，$F_N(z) = 1-(1-F(z))^n$。

题 ★★★（指数串并联，经典）：$n$ 个独立 $E(\lambda)$ 元件，求串联（取 min）和并联（取 max）的寿命分布。
解

串联（min）：$F_N(z) = 1-(e^{-\lambda z})^n = 1-e^{-n\lambda z}$，即 $N\sim E(n\lambda)$。

并联（max）：$F_M(z) = (1-e^{-\lambda z})^n$，无简单形式。$E(M) = \dfrac{1}{\lambda}\sum_{k=1}^n\dfrac{1}{k}$（调和级数）。

结论必记：$n$ 个 i.i.d. $E(\lambda)$ 取 min 仍是指数分布，参数变 $n\lambda$。

五、商的分布

$Z = Y/X$（$X\neq 0$）：

$$f_Z(z) = \int_{-\infty}^{+\infty}|x|\,f(x, xz)\dd x$$

独立时：$f_Z(z) = \int|x|f_X(x)f_Y(xz)\dd x$。

六、必记结论 ★★★

$X^2+Y^2$ 的分布：$X, Y\sim N(0, 1)$ 独立 $\Rightarrow X^2+Y^2\sim\chi^2(2) = E(1/2)$。

密度：$f(z) = \dfrac{1}{2}e^{-z/2},\ z > 0$。

这条结论在多年大题压轴里被反复利用，特别是涉及"求圆内点到原点距离的分布"的几何题。

例（旋转对称）：$(X, Y)\sim N(0, 1, 0, 1, 0)$（独立），求 $R = \sqrt{X^2+Y^2}$ 的分布。
解

$R^2 = X^2+Y^2\sim E(1/2)$。$F_{R^2}(t) = 1-e^{-t/2}$。

$F_R(r) = P(R\leq r) = P(R^2\leq r^2) = 1-e^{-r^2/2},\ r > 0$

$f_R(r) = re^{-r^2/2}$ —— 这是 Rayleigh 分布！

七、易错点清单

  • 卷积分段错误：忘记 $f_X$ 和 $f_Y(z-x)$ 必须同时非零，画图！
  • 线性变换忘除以系数：周长 $Z = 2(X+Y)$ 的密度要 $\frac{1}{2}f_W(z/2)$
  • min 公式："1 减各自补集乘积"，注意补集
  • 可加性忘加独立性条件：所有可加性都需要独立
  • 二项可加要求同 $p$：$B(n_1, p_1) + B(n_2, p_2)$ 不等于 $B(n_1+n_2, ?)$
  • 指数无可加性：但视为 $\Gamma(1, \lambda)$ 时有
  • 商分布忘 $|x|$ 系数：$f_Z(z) = \int|x|f(x, xz)\dd x$
记忆口诀：
  • "和用卷积，max 乘 $F$，min 用 $1-(1-F)^n$"
  • "可加性永远需要独立"
  • "周长记得乘 1/2"
  • "两 N(0,1) 平方和 = $\chi^2(2) = E(1/2)$"

八、真题套路 · 二级结论 · 速算技巧

题型决策树（按 $Z$ 类型）

$Z$ 类型方法关键
$Z = X+Y$（独立）卷积 $\int f_X(x)f_Y(z-x)\dd x$画图分段
$Z = X+Y$（不独立）$\int f(x, z-x)\dd x$用联合密度
$Z = \max(X_i)$$F_Z = \prod F_{X_i}$独立时直接
$Z = \min(X_i)$$F_Z = 1-\prod(1-F_{X_i})$用补集
$Z = X/Y$$\int|x|f(x,xz)\dd x$带 $|x|$
$Z = X-Y$ 或 $X\cdot Y$分布函数法分段
$Z = a(X+Y)$ 周长型先卷积，再线性变换记得乘 $1/a$

必背二级结论（卷积速查）

  1. $U(0,1)+U(0,1) = $ 三角分布（密度 $z$ 在 $[0,1]$，$2-z$ 在 $[1,2]$）
  2. 独立正态相加保正态：$X+Y\sim N(\mu_1+\mu_2,\sigma_1^2+\sigma_2^2)$
  3. 独立 Poisson 相加保 Poisson：$P(\lambda_1)+P(\lambda_2) = P(\lambda_1+\lambda_2)$
  4. 独立同 $p$ 二项相加：$B(n_1,p)+B(n_2,p) = B(n_1+n_2,p)$（必须同 $p$！）
  5. $n$ 个独立 $E(\lambda)$ 取 min：$\sim E(n\lambda)$（参数变大）
  6. $X^2+Y^2$（$X,Y\sim N(0,1)$ 独立）：$\sim\chi^2(2) = E(1/2)$，密度 $\frac{1}{2}e^{-z/2}$
  7. $\sqrt{X^2+Y^2}$（$X,Y\sim N(0,1)$ 独立）：Rayleigh 分布，密度 $re^{-r^2/2},\,r>0$
  8. $n$ 个独立 $E(\lambda)$ 之和：$\sim\Gamma(n,\lambda)$，密度 $\frac{\lambda^n}{(n-1)!}x^{n-1}e^{-\lambda x}$
  9. 独立 $\chi^2$ 相加：$\chi^2(n_1)+\chi^2(n_2) = \chi^2(n_1+n_2)$
  10. $n$ 个 i.i.d. $U(0,1)$ 中位数渐近 $N(1/2, 1/(4n))$（CLT 应用）

速算与解题技巧

  1. 看到独立正态相加，直接套可加性，不用卷积
  2. 卷积分段技巧：找 $f_X(x) > 0$ 和 $f_Y(z-x) > 0$ 同时成立的 $(x,z)$ 区域，画图分段
  3. 周长 / 距离 / 倍数：先求 $X+Y$ 或 $\sqrt{X^2+Y^2}$，再用变量代换
  4. "$n$ 个元件串联取 min" → 直接 $E(n\lambda)$
  5. 检查是否独立：可加性必须独立！否则 $D(X+Y)\neq D(X)+D(Y)$
  6. 验算技巧：算完 $f_Z$ 后积分 = 1 检验

常错"小坑"清单

  • 卷积分段错误：忘记 $f_X(x)$ 与 $f_Y(z-x)$ 同时非零的范围 → 画图！
  • 线性变换忘除以系数：周长 $Z = 2(X+Y)$ 的密度要乘 $1/2$（$Z/2 = X+Y$ 的卷积）
  • $\min$ 公式记错："$1$ 减各自补集乘积"，不要忘减号
  • 用可加性忘加独立性条件：所有可加性都需要独立
  • 二项可加要求同 $p$：$B(n_1,p_1)+B(n_2,p_2)$ 不是 $B(n_1+n_2,?)$
  • 指数无可加性：但视为 $\Gamma(1,\lambda)$ 时有
