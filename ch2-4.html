2.4 随机变量的函数及其分布 ⭐⭐⭐

本节真题考频：14 套真题命中 10+ 套。每年大题第 15 题（9 分）频繁出现。
典型出题：$Y=X^2$（22-23-2、15-16-1）· $Y=e^X$（18-19-2）· $Y=\sqrt X$（19-20-1）· $Y=|X|$（多次）· $Y=\min(X,2)$（23-24-1）· $Y=e^{-X}$（17-18-2）。

一、离散型：取值合并

$Y = g(X)$，$X$ 取 $\{x_k\}$ 概率 $\{p_k\}$，则

$$P(Y = y_i) = \sum_{k:\,g(x_k) = y_i} p_k$$

把映射到同一 $y_i$ 的所有 $x_k$ 概率合并即可。

例 1：$X$ 取 $-1, 0, 1, 2$，概率 $0.2, 0.3, 0.4, 0.1$。求 $Y = X^2$ 的分布律。
解

$Y$ 取值 $0, 1, 4$。

$P(Y=0) = P(X=0) = 0.3$；$P(Y=1) = P(X=-1) + P(X=1) = 0.2+0.4 = 0.6$；$P(Y=4) = P(X=2) = 0.1$。

二、连续型方法 A：分布函数法（万能！）

⭐ 三步走（最稳）
  1. 先写 $F_Y(y) = P(Y \leq y) = P(g(X) \leq y)$
  2. 把 $\{g(x) \leq y\}$ 反解成 $x$ 的区域
  3. 用 $f_X$ 积分，再求导得 $f_Y$

难点：对 $g(x)\leq y$ 反解时，可能要根据 $y$ 的不同范围分段讨论；定义域要写完整。

例 2（绝对值）：$X\sim U(-1,1)$，求 $Y = |X|$ 的密度。
解

$f_X(x) = 1/2,\ -1 < x < 1$。当 $y < 0$：$F_Y(y) = 0$。当 $y\geq 1$：$F_Y(y) = 1$。当 $0\leq y < 1$：

$$F_Y(y) = P(|X|\leq y) = P(-y\leq X\leq y) = \int_{-y}^y\dfrac{1}{2}\dd x = y$$

$f_Y(y) = F_Y'(y) = 1,\ y\in(0,1)$。即 $Y\sim U(0,1)$。

题 ★★★ 22-23-2 第 4 题（双侧指数 $Y=X^2$）：$X$ 密度 $f(x) = \dfrac{1}{2}e^{-|x|}$，求 $Y = X^2$ 的密度。
解

$y\leq 0$：$F_Y = 0$。$y > 0$：

$$F_Y(y) = P(X^2\leq y) = P(-\sqrt y\leq X\leq\sqrt y) = \int_{-\sqrt y}^{\sqrt y}\dfrac{1}{2}e^{-|x|}\dd x = 1-e^{-\sqrt y}$$ $$f_Y(y) = F_Y'(y) = \dfrac{e^{-\sqrt y}}{2\sqrt y},\ y > 0$$

关键：偶函数对称性 → 积分上限去对称变 $2\int_0^{\sqrt y}\frac{1}{2}e^{-x}\dd x = 1-e^{-\sqrt y}$。

题 ★★★（$Y=X^2$ 导出 $\chi^2(1)$）：$X\sim N(0,1)$，求 $Y=X^2$ 的密度。
解

$y\leq 0$：$F_Y = 0$。$y > 0$：

$$F_Y(y) = P(X^2\leq y) = P(-\sqrt y\leq X\leq\sqrt y) = \Phi(\sqrt y)-\Phi(-\sqrt y) = 2\Phi(\sqrt y)-1$$ $$f_Y(y) = \dfrac{1}{\sqrt y}\varphi(\sqrt y) = \dfrac{1}{\sqrt{2\pi y}}e^{-y/2},\ y > 0$$

这就是自由度 1 的 $\chi^2$ 分布 $\chi^2(1)$，等价于 $E(1/2)$。第 6 章会重点考。

题 ★★★ 23-24-1 第 2 题（min 函数，混合型！）：$X\sim E(\lambda)$，求 $Y=\min(X, 2)$ 的分布。
解

$Y$ 既有连续部分（$Y < 2$ 时 $Y = X$）又有离散质点（$Y = 2$ 时 $X\geq 2$）。

$Y < 2$：$F_Y(y) = P(\min(X,2)\leq y) = P(X\leq y) = 1-e^{-\lambda y}$，$y\in(0,2)$

$Y = 2$：$P(Y = 2) = P(X\geq 2) = e^{-2\lambda}$（这是个跳跃，质点！）

$Y\geq 2$：$F_Y(y) = 1$。

所以 $Y$ 的分布函数 $F_Y$ 在 $[0, 2)$ 是 $1-e^{-\lambda y}$，在 $y=2$ 跳到 1。$Y$ 不是连续型，是混合型！这就是 min(X, c) 的常见陷阱。

三、连续型方法 B：公式法（仅严格单调）

⭐ 公式法

若 $g$ 在 $X$ 的支撑上严格单调可导，反函数 $x = h(y)$，则

$$f_Y(y) = f_X(h(y))\cdot|h'(y)|$$

定义域 = $g$ 的值域。

线性变换（最常用！）

$Y = aX+b$（$a\neq 0$）：

$$f_Y(y) = \dfrac{1}{|a|}f_X\!\left(\dfrac{y-b}{a}\right)$$

正态特例：$X\sim N(\mu,\sigma^2) \Rightarrow Y = aX+b\sim N(a\mu+b, a^2\sigma^2)$

分段单调推广

若 $g$ 在 $X$ 支撑上分段单调，每段反函数 $h_i$：

$$f_Y(y) = \sum_i f_X(h_i(y))\cdot|h_i'(y)|$$

每个 $h_i$ 的定义域需正确确定。

题 ★★（对数正态）：$X\sim N(\mu,\sigma^2)$，$Y = e^X$。
解

$g(x) = e^x$ 严格增，$h(y) = \ln y$，$h'(y) = 1/y$。值域 $y > 0$。

$$f_Y(y) = \dfrac{1}{y\sqrt{2\pi}\sigma}\exp\!\left[-\dfrac{(\ln y-\mu)^2}{2\sigma^2}\right],\ y > 0$$

这是对数正态分布，常用于金融建模。

题（$Y = \sin X$，分段单调）：$X\sim U(0,\pi)$，求 $Y = \sin X$ 的密度。
解

$f_X(x) = 1/\pi,\ 0 < x < \pi$。$y = \sin x$ 在 $(0,\pi)$ 不严格单调，分两段：

  • $x\in(0,\pi/2)$：$h_1(y) = \arcsin y$，$h_1'(y) = 1/\sqrt{1-y^2}$
  • $x\in(\pi/2,\pi)$：$h_2(y) = \pi-\arcsin y$，$h_2'(y) = -1/\sqrt{1-y^2}$

对 $y\in(0,1)$：

$$f_Y(y) = \dfrac{1}{\pi}\cdot\dfrac{1}{\sqrt{1-y^2}}+\dfrac{1}{\pi}\cdot\dfrac{1}{\sqrt{1-y^2}} = \dfrac{2}{\pi\sqrt{1-y^2}}$$

四、概率积分变换（满分笔记重点）

若 $X$ 的分布函数 $F_X$ 严格单调连续，则

$$Y = F_X(X)\sim U(0,1)$$

用途：Monte Carlo 模拟。给定 $U\sim U(0,1)$，则 $X = F_X^{-1}(U)$ 服从 $F_X$。

例：模拟指数分布 $E(\lambda)$。
解

$F(x) = 1-e^{-\lambda x}$，反解 $X = -\ln(1-U)/\lambda$（$U\sim U(0,1)$）。

简化 $X = -\ln U/\lambda$（因为 $1-U$ 也服从 $U(0,1)$）。

五、必考题型总结

题型方法关键
$Y = aX+b$公式法（线性）正态保正态
$Y = X^2$分布函数法（双值反函数）$y > 0$，分子有 $\sqrt y$；$X\sim N(0,1)$ 时得 $\chi^2(1)$
$Y = |X|$分布函数法分对称性
$Y = e^X$公式法正态 → 对数正态
$Y = \min(X, c)$分布函数法混合型！$y = c$ 处有质点
$Y = \max(X, c)$分布函数法同上，$y = c$ 处质点
$Y = F_X(X)$定义$\sim U(0,1)$
$Y = \sin X / \cos X$分段单调推广$(0,\pi)$ 上不单调，分段

六、易错点清单（每年都有人栽）

  • 用公式法时 $g$ 非单调：例如 $Y = X^2$ 直接套公式法漏掉一半
  • 忘记定义域：$Y$ 的定义域 = $g$ 的值域，要明确写
  • $Y = \min/\max(X, c)$ 当成连续型：实际是混合型，含离散质点 $P(Y = c)$
  • 公式法忘加 $|h'|$ 的绝对值
  • 反函数定义域写错：例如 $Y = X^2,\ X\sim N(0,1)$，$Y$ 是 $[0,\infty)$ 不是 $\mathbb R$
  • 双值反函数：$X^2$、$|X|$、$\cos X$ 等要分段处理
记忆口诀：
  • "不严格单调，分布函数法；严格单调，公式法"
  • "看到 min/max（X, c），警惕混合型"
  • "$Y = X^2$，$X\sim N(0,1)$，结果是 $\chi^2(1)$"

七、真题套路 · 二级结论 · 速算技巧

题型决策树（按 $g(x)$ 类型）

  1. $g$ 严格单调（如 $aX+b, e^X, \ln X$）→ 公式法 $f_Y(y) = f_X(h(y))|h'(y)|$
  2. $g$ 分段单调（如 $X^2, |X|, \sin X$）→ 公式法分段相加 $\sum f_X(h_i)|h_i'|$
  3. $g$ 不单调或难解 → 分布函数法（万能但繁琐）
  4. $g$ 含 max/min(X, c) → 分布函数法 + 注意混合型（有质点）

必背二级结论

  1. 正态线性保正态：$X\sim N(\mu, \sigma^2),\,Y = aX+b\sim N(a\mu+b, a^2\sigma^2)$
  2. $X\sim N(0,1)\Rightarrow X^2\sim\chi^2(1)$，密度 $\dfrac{1}{\sqrt{2\pi y}}e^{-y/2},\,y>0$
  3. $X\sim U(0,1)\Rightarrow -\ln X\sim E(1)$（指数随机数生成）
  4. $X\sim$ 任意连续 $F_X$，则 $Y = F_X(X)\sim U(0,1)$（概率积分变换）
  5. $X\sim U(a,b)\Rightarrow Y = (X-a)/(b-a)\sim U(0,1)$（线性归一）
  6. $X\sim N(\mu,\sigma^2)\Rightarrow Y = e^X$ 服从对数正态：$f_Y(y) = \dfrac{1}{y\sqrt{2\pi}\sigma}\exp[-(\ln y-\mu)^2/(2\sigma^2)]$
  7. $X\sim N(0,1)\Rightarrow |X|$ 服从半正态分布：$f(y) = \dfrac{2}{\sqrt{2\pi}}e^{-y^2/2},\,y>0$，$E|X| = \sqrt{2/\pi}$

速算与解题技巧

  1. 看到 $Y = X^2$，立刻想"双值反函数"，结果含 $\sqrt y$，定义域 $y>0$
  2. 看到 $Y = aX+b$，正态保正态，无需推导直接写答案
  3. 看到 $Y = \min(X, c)$ 或 $\max(X, c)$，警惕混合型！ $P(Y=c)>0$
  4. $X\sim N(0,1)$ 的偶函数：$E|X| = \sqrt{2/\pi}\approx 0.798$（必背）
  5. $F$ 反求 $f$：$f(y) = F'(y)$（在 $f$ 连续点）
  6. 定义域反推：$g(x)$ 在 $X$ 支撑上的值域 = $Y$ 的支撑

常错"小坑"清单

  • 公式法用在非单调函数：$Y=X^2$ 直接用公式法会漏一半，必须分段
  • 忘 $|h'(y)|$ 的绝对值 —— 单调减时 $h'<0$，必须取绝对值
  • $Y = \min/\max(X,c)$ 当作连续型：实际有质点 $P(Y=c)>0$，密度只在 $y\neq c$ 定义
  • 反函数定义域写错：$Y = X^2,\,X\in\mathbb R$ 时 $Y\in[0,\infty)$
  • 分段单调时忘加：$Y = X^2$ 时分段反函数 $\sqrt y, -\sqrt y$ 各贡献一项
