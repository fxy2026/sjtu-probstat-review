一、随机变量

定义

样本空间 $\Omega$ 上的实值函数 $X(\omega):\Omega\to\mathbb R$ 称为随机变量。

把"事件"提升到"数值"，便于用微积分工具研究。

三种类型：
  • 离散型：$X$ 取值至多可列（如 $\{0, 1, 2, \ldots\}$）
  • 连续型：分布函数 $F(x)$ 可写为某非负函数的变上限积分
  • 混合型 / 一般型：既非纯离散也非纯连续（如 $\min(X, c)$）

三、典型例题

题 ★（待定常数）：$F(x) = A+B\arctan x$ 是某随机变量的分布函数，求 $A, B$ 及 $P(|X|<1)$。
解

$F(-\infty) = A-B\pi/2 = 0$，$F(+\infty) = A+B\pi/2 = 1$，解得 $A = 1/2,\,B = 1/\pi$。

$$P(|X|<1) = F(1-0)-F(-1) = F(1)-F(-1) = \dfrac{1}{2}+\dfrac{1}{4}-\left(\dfrac{1}{2}-\dfrac{1}{4}\right) = \dfrac{1}{2}$$

这是 Cauchy 分布！

题（线性组合是否为分布函数）：已知 $F_1, F_2$ 是分布函数。$aF_1(x)+bF_2(x)$ 是分布函数的充要条件？
解

$F(+\infty) = a+b = 1$；非减需 $a, b\geq 0$。结论：$a, b\geq 0$ 且 $a+b = 1$（凸组合）。

$F(-\infty) = 0$ 自动成立。

五、真题套路 · 二级结论 · 速算技巧

必背二级结论

  1. 分布函数三性质：单调不减 + 右连续 + $F(-\infty)=0, F(+\infty)=1$
  2. $P(X=a) = F(a)-F(a-0)$（跳跃高度）—— 离散点的概率
  3. $P(X（不含 $a$）；$P(X\leq a) = F(a)$（含 $a$）
  4. $P(a；$P(a\leq X\leq b) = F(b)-F(a-0)$
  5. $P(X>a) = 1-F(a)$；$P(X\geq a) = 1-F(a-0)$
  6. 连续型 $P(X=a) = 0$，所以含/不含端点不影响概率
  7. $aF_1+bF_2$ 是分布函数 ⇔ $a, b\geq 0$ 且 $a+b=1$（凸组合）

速算与解题技巧

  1. 求待定常数：用 $F(-\infty)=0$ 和 $F(+\infty)=1$ 列方程
  2. 判断是分布函数：检查 3 性质，最快是边界条件
  3. 含/不含等号的边界：右连续 → 含 $=$ 归右值
  4. 混合型识别：$F$ 既有连续部分又有跳跃

  • "右连续"写成"左连续"（最常见错）
