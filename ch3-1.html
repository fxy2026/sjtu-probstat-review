3.1 二维随机变量及其分布 ⭐⭐⭐

本节真题考频：14/14 套真题命中（100%）。每年大题第 14 题的第一小问必出。
典型出题：给 $f(x, y)$ 求归一化常数 $c$ · 求边缘 · 求 $P((X, Y)\in D)$ · 二维正态边缘判别。

一、联合分布函数

定义
$$F(x, y) = P(X\leq x,\,Y\leq y)$$
基本性质
  • $0\leq F\leq 1$
  • 对 $x, y$ 分别单调不减、右连续
  • $F(-\infty, y) = F(x, -\infty) = 0$，$F(+\infty, +\infty) = 1$
  • 矩形概率 $\geq 0$：$F(b, d)-F(b, c)-F(a, d)+F(a, c)\geq 0$（$a

满足这 4 条 ⇔ 是某二维随机变量的分布函数。

二、离散型联合分布律

$(X, Y)$ 取离散值 $(x_i, y_j)$：

$$p_{ij} = P(X = x_i, Y = y_j),\quad p_{ij}\geq 0,\,\sum_{i,j}p_{ij} = 1$$

边缘分布律：

$$p_{i\cdot} = P(X = x_i) = \sum_j p_{ij},\quad p_{\cdot j} = P(Y = y_j) = \sum_i p_{ij}$$

三、连续型联合密度

$$F(x, y) = \int_{-\infty}^x\int_{-\infty}^y f(u, v)\dd u\dd v$$

性质：$f\geq 0$，$\iint f = 1$，$\dfrac{\partial^2 F}{\partial x\partial y} = f$（连续点）。

边缘密度：

$$f_X(x) = \int_{-\infty}^{+\infty}f(x, y)\dd y,\quad f_Y(y) = \int_{-\infty}^{+\infty}f(x, y)\dd x$$

区域概率：$P((X, Y)\in D) = \iint_D f\dd x\dd y$

四、两种常见二维分布

1. 二维均匀分布

$$f(x, y) = \begin{cases}1/S_G,&(x, y)\in G\\0,&\text{其他}\end{cases}$$

$S_G$ = 区域 $G$ 的面积。

2. 二维正态 $N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$

$$f(x, y) = \dfrac{1}{2\pi\sigma_1\sigma_2\sqrt{1-\rho^2}}\exp\!\left[-\dfrac{1}{2(1-\rho^2)}\left(\dfrac{(x-\mu_1)^2}{\sigma_1^2}-2\rho\dfrac{(x-\mu_1)(y-\mu_2)}{\sigma_1\sigma_2}+\dfrac{(y-\mu_2)^2}{\sigma_2^2}\right)\right]$$

边缘均为一维正态：$X\sim N(\mu_1, \sigma_1^2),\,Y\sim N(\mu_2, \sigma_2^2)$

但反之不真！ 边缘正态不一定来自二维正态（存在反例）。

五、典型例题

题 ★★★（常见考题）：$f(x, y) = ky$，$D = \{(x, y): 0\leq x\leq y\leq 1\}$。求 $k$、$P(Y > 1/2)$、边缘密度。
解

定 $k$：$\iint f = k\int_0^1\dd x\int_x^1 y\dd y = k\int_0^1\dfrac{1-x^2}{2}\dd x = k\cdot\dfrac{1}{3} = 1\Rightarrow k = 3$

$P(Y > 1/2)$：积分区域 $\{0\leq x\leq y, 1/2 < y\leq 1\}$，即 $y\in(1/2, 1], x\in[0, y]$：

$$P = 3\int_{1/2}^1\int_0^y y\,\dd x\,\dd y = 3\int_{1/2}^1 y^2\,\dd y = 3\cdot\dfrac{1}{3}[1-1/8] = \dfrac{7}{8}$$

边缘密度：

$$f_X(x) = 3\int_x^1 y\,\dd y = \dfrac{3}{2}(1-x^2),\;0\leq x\leq 1$$ $$f_Y(y) = 3\int_0^y y\,\dd x = 3y^2,\;0\leq y\leq 1$$

验证 $f\geq 0$ 全区域成立 ✓，$\iint f = 1$ ✓。

题（单位圆均匀分布的边缘）：$(X, Y)$ 在 $x^2+y^2\leq 1$ 均匀分布。求边缘 $f_X$。
解

$f(x, y) = 1/\pi$。$|x| < 1$ 时：

$$f_X(x) = \int_{-\sqrt{1-x^2}}^{\sqrt{1-x^2}}\dfrac{1}{\pi}\dd y = \dfrac{2\sqrt{1-x^2}}{\pi}$$

不是均匀！ 边缘形如"椭圆型"。这表明二维均匀分布的边缘不必均匀。

六、易错点清单

  • 边缘分布不能唯一决定联合分布：相同边缘可能对应不同联合（最常见的考点）
  • 积分上下限随区域 $D$ 变化，需画图判断顺序
  • 边缘密度积分要丢另一变量的支撑限制（如 $y$ 的范围依赖 $x$）
  • 二维正态边缘是一维正态，但反之不真
  • $\rho = 0$ ⇔ 独立 仅在二维正态成立
记忆口诀：
  • "边缘 = 把另一变量积分掉"
  • "区域概率 = 区域上密度积分"
  • "二维正态边缘正态；反之未必"

七、真题套路 · 二级结论 · 速算技巧

题型套路（题 14 的第一小问）

  1. 归一化求 $c$：$\iint c\cdot g(x,y)\mathbf 1_D\dd x\dd y = 1$
  2. 求边缘：$f_X(x) = \int_{\{y: f(x,y)>0\}}f(x,y)\dd y$（积分上下限随 $x$ 变）
  3. 区域概率：$P((X,Y)\in A) = \iint_A f\dd x\dd y$（画图！）

必背二级结论

  1. 二维分布函数矩形概率：$F(b,d)-F(b,c)-F(a,d)+F(a,c) = P(a
  2. 边缘从联合 → 唯一；联合从边缘 → 不唯一
  3. 二维正态边缘是一维正态：$N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)\Rightarrow X\sim N(\mu_1,\sigma_1^2)$；反之未必
  4. 二维均匀 $f = 1/S_G$（区域面积的倒数）
  5. 单位圆均匀的边缘：$f_X(x) = \frac{2\sqrt{1-x^2}}{\pi}$（不是均匀！）
  6. 对称区域 + 对称密度的边缘对称：若 $f(x,y) = f(-x,y)$，则 $f_X$ 是偶函数
  7. $f(x,y) = f_X\cdot f_Y$ + 矩形支撑 ⇒ 独立

速算与解题技巧

  1. 画区域图是必须的—— 决定积分上下限
  2. 积分顺序选择：选积分容易的方向先积
  3. 对称性利用：偶函数对称积分简化
  4. 二维正态记参数：$\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho$
  5. 验证概率 $\leq 1$：算完后用边界条件检验

常错"小坑"清单

  • 积分上下限随 $x$ 变：边缘密度积分要看支撑
  • "边缘 + 独立 → 联合" 错：只有独立时 $f = f_X f_Y$
  • 二维均匀的边缘不一定均匀（单位圆是反例）
  • $\rho = 0$ ⇔ 独立 仅在二维正态
