5.1 Chebyshev 不等式与依概率收敛 ⭐⭐⭐

本节真题考频：14 套真题命中 12 套（86%）。与 CLT 联考是必出大题第 16 题。
典型出题：用 Chebyshev 估计概率下界 + CLT 求精确值的对比 · 灯泡寿命 · 营业额估计 · 配对问题。

一、Chebyshev 不等式

设 $E(X) = \mu,\,D(X) = \sigma^2$ 存在，则对任意 $\epsilon > 0$：

$$P(|X-\mu|\geq\epsilon)\leq\dfrac{\sigma^2}{\epsilon^2}$$

或等价：

$$P(|X-\mu|<\epsilon)\geq 1-\dfrac{\sigma^2}{\epsilon^2}$$
$k\sigma$ 形式
$$P(|X-\mu|$k = 2$ 时 $\geq 3/4$；$k = 3$ 时 $\geq 8/9$。

这是下界，正态分布实际更高（68/95/99.7%）。

本质：Chebyshev 不等式只需期望和方差存在，对任意分布都成立。是非常普适但粗糙的估计工具。

二、依概率收敛

$Y_n\xrightarrow{P}a$ 定义：对任意 $\epsilon > 0$，

$$\lim_{n\to\infty}P(|Y_n-a|\geq\epsilon) = 0$$

等价：$\lim P(|Y_n-a|<\epsilon) = 1$。

依概率收敛是"概率上越来越接近"，比几乎处处收敛弱。是大数定律的标准收敛形式。

  3. Chebyshev 给下界，CLT 给精确值

六、历年真题原型

题 ★★★★ 21-22-2 第 9 题（10000 盏灯，Chebyshev 给下界）：每盏灯独立开灯，概率 $0.7$。求"同时开着的灯数在 $6900$ 到 $7100$ 之间"的概率至少为多少。
解

设开灯数 $S = \sum_{i=1}^{10000}X_i\sim B(10000,0.7)$。

$E(S) = np = 10000\times 0.7 = 7000$，$\D(S) = np(1-p) = 10000\times 0.7\times 0.3 = 2100$。

事件 $\{6900\leq S\leq 7100\}$ 即 $\{|S-7000|\leq 100\}$，套 Chebyshev：

$$P(|S-7000|\leq 100)\geq 1-\dfrac{\D(S)}{100^2} = 1-\dfrac{2100}{10000} = 1-0.21 = 0.79$$

故概率至少 0.79（下界）。题目问"至少"就用 Chebyshev，不用 CLT。

题 ★★★ 配对问题 / 依概率收敛（20-21-2 第 18 题型，压轴常客）：$n$ 个球随机放入 $n$ 个盒（每盒恰一球的全排列），配对数 $S_n = \sum_{i=1}^n X_i$（$X_i$ = 第 $i$ 球归位）。已知 $E(S_n) = 1,\D(S_n) = 1$（与 $n$ 无关）。证明 $\lim_{n\to\infty}P(|S_n-1|\geq n\epsilon) = 0$。
解

$E(X_i) = 1/n$，$E(X_iX_j) = \dfrac{1}{n(n-1)}$，由此可算出 $E(S_n) = 1,\D(S_n) = 1$（与 $n$ 无关，必背）。Chebyshev：

$$P(|S_n-1|\geq n\epsilon)\leq\dfrac{\D(S_n)}{(n\epsilon)^2} = \dfrac{1}{n^2\epsilon^2}\to 0\quad(n\to\infty)$$

即 $S_n/n\xrightarrow{P}0$。证毕。关键：$\D(S_n) = 1$ 是与 $n$ 无关的常数，所以除以 $(n\epsilon)^2$ 后趋于 0。

七、必背块

  • Chebyshev：$P(|X-\mu|\geq\epsilon)\leq\dfrac{\sigma^2}{\epsilon^2}$，等价 $P(|X-\mu|<\epsilon)\geq 1-\dfrac{\sigma^2}{\epsilon^2}$。
  • $k\sigma$ 形式：$P(|X-\mu|
  • 二项专用：$S\sim B(n,p)$ 时 $E(S) = np,\,\D(S) = np(1-p)$，直接代入 Chebyshev。
  • 配对问题 $E(S_n) = 1,\,\D(S_n) = 1$（与 $n$ 无关，必背常数）。
  • 依概率收敛：$Y_n\xrightarrow{P}a\Leftrightarrow\lim_n P(|Y_n-a|\geq\epsilon) = 0$（$\forall\epsilon>0$）。
  • Chebyshev 推论：$\D(Y_n)\to 0$ 且 $E(Y_n) = a$（或 $\to a$）$\Rightarrow Y_n\xrightarrow{P}a$。证依概率收敛的标准武器。

八、易错点

  • Chebyshev 给的是 $\geq$ 下界，不是 $=$。题目问"至少多少概率"才用它；问"近似多少"用 CLT。
  • $\epsilon$ 是绝对偏差不是相对偏差；当 $\epsilon\leq\sigma$ 时下界 $\leq 0$ 无意义（射手例就是这种"偏差太小"的情形）。
  • 区间最好关于 $\mu$ 对称才能直接套 $|X-\mu|<\epsilon$；不对称时取离 $\mu$ 较近的半边当 $\epsilon$（更保守）。
  • 大数律是依概率收敛，不是几乎处处（a.s.），强大数律才是 a.s.。
