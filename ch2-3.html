2.3 连续型随机变量 ⭐⭐

本节真题考频：14/14 套真题命中（100%）。每年至少 1-2 道选择 + 大题中常作工具。
典型出题：指数失效 · 正态 $N(\mu, \sigma^2)$ 标准化查表 · Rayleigh · 密度积分求归一化 · $3\sigma$ 原则。

一、概率密度函数

定义

$X$ 的分布函数 $F(x)$ 可写成

$$F(x) = \int_{-\infty}^x f(t)\dd t$$

$f(x)$ 是概率密度。

密度的性质
  • $f(x)\geq 0$
  • $\int_{-\infty}^{+\infty}f(x)\dd x = 1$
  • $f$ 连续点 $F'(x) = f(x)$
  • $P(a
  • $P(X = x_0) = 0$（但事件未必不发生，"零测集"）
连续型 $X$ 取任意单点概率为 0，所以 $P(a\leq X\leq b) = P(a边界与否不影响。

二、均匀分布 $U(a, b)$

$$f(x) = \begin{cases}\dfrac{1}{b-a},&ab\end{cases}$$

$E(X) = \dfrac{a+b}{2},\,D(X) = \dfrac{(b-a)^2}{12}$

三、指数分布 $E(\lambda)$ ⭐

$$f(x) = \begin{cases}\lambda e^{-\lambda x},&x\geq 0\\0,&x<0\end{cases}\quad F(x) = 1-e^{-\lambda x}\;(x\geq 0)$$

$E(X) = 1/\lambda,\,D(X) = 1/\lambda^2$

描述独立随机事件发生的时间间隔。

⭐ 无记忆性（连续唯一！）
$$P(X>s+t\mid X>s) = P(X>t)$$

证明：

$$\dfrac{P(X>s+t)}{P(X>s)} = \dfrac{e^{-\lambda(s+t)}}{e^{-\lambda s}} = e^{-\lambda t} = P(X>t)$$

"已经等了 $s$，再等 $t$ 的概率与从头等 $t$ 一样"。

结论：连续分布中唯一具有无记忆性的是指数分布。

题 ★：到达时间 $T\sim E(\lambda)$，已知 $T > 8$ 分钟，求 $T > 18$ 的概率。
解

$P(T>18\mid T>8) = P(T>10) = e^{-10\lambda}$。

指数与 Poisson 的关系

Poisson 流（率 $\lambda$）的相邻事件间隔时间 $\sim E(\lambda)$。

反过来：若 i.i.d. 间隔 $\sim E(\lambda)$，则单位时间内事件数 $\sim P(\lambda)$。

这是排队论的基础。

四、正态分布 $N(\mu, \sigma^2)$ ⭐⭐⭐

$$f(x) = \dfrac{1}{\sqrt{2\pi}\sigma}\exp\!\left[-\dfrac{(x-\mu)^2}{2\sigma^2}\right]$$

$E(X) = \mu,\,D(X) = \sigma^2$

$\mu$ 决定位置（对称轴），$\sigma$ 决定胖瘦（越小越尖）。

⭐ 标准化定理
$$X\sim N(\mu, \sigma^2)\Rightarrow\dfrac{X-\mu}{\sigma}\sim N(0, 1)$$

记标准正态分布函数为 $\Phi$，则

$$P(X\leq x) = \Phi\!\left(\dfrac{x-\mu}{\sigma}\right)$$

对称性：$\Phi(-x) = 1-\Phi(x)$。

⭐ $3\sigma$ 原则（必背！）
  • $P(|X-\mu|<\sigma)\approx 0.6826$
  • $P(|X-\mu|<2\sigma)\approx 0.9544$
  • $P(|X-\mu|<3\sigma)\approx 0.9974$

正态分布几乎所有概率集中在 $\mu\pm 3\sigma$ 内。工业质量控制核心。

常用分位数（必背）
$\alpha$0.100.050.0250.010.005
$u_\alpha$1.281.6451.962.332.575

定义：$P(X>u_\alpha) = \alpha$（上侧 $\alpha$ 分位数）。

题 ★：$X\sim N(7.5, 100)$，求 $P(|X|\leq 10)$。
解

$\sigma = 10$。

$$P(|X|\leq 10) = P(-10\leq X\leq 10) = \Phi\!\left(\dfrac{10-7.5}{10}\right)-\Phi\!\left(\dfrac{-10-7.5}{10}\right) = \Phi(0.25)-\Phi(-1.75)$$ $$= \Phi(0.25)-[1-\Phi(1.75)] = 0.5987-(1-0.9599) = 0.5586$$
题（满分笔记推导）：$X\sim N(\mu, \sigma^2)$，证明 $E(X) = \mu$。
证明
$$E(X) = \int_{-\infty}^{+\infty}\dfrac{x}{\sqrt{2\pi}\sigma}e^{-(x-\mu)^2/(2\sigma^2)}\dd x$$

令 $y = x-\mu$，$\dd y = \dd x$：

$$= \int_{-\infty}^{+\infty}\dfrac{y+\mu}{\sqrt{2\pi}\sigma}e^{-y^2/(2\sigma^2)}\dd y$$ $$= \underbrace{\int\dfrac{y}{\sqrt{2\pi}\sigma}e^{-y^2/(2\sigma^2)}\dd y}_{=0\,\text{（奇函数）}}+\mu\cdot\underbrace{\int\dfrac{1}{\sqrt{2\pi}\sigma}e^{-y^2/(2\sigma^2)}\dd y}_{=1\,\text{（归一化）}} = \mu$$

五、易错点清单

  • 连续型 $P(X = a) = 0$ 但事件未必不发生
  • 正态标准化分母用 $\sigma$，不是 $\sigma^2$
  • $\Phi(-x) = 1-\Phi(x)$ 忘减负数情况
  • 指数分布参数 $\lambda$ 方向：$E(X) = 1/\lambda$（不是 $\lambda$）
  • 无记忆性是连续分布的"指数唯一"，离散是"几何唯一"
  • $X\sim N(\mu, \sigma^2)$ 中第二参数是方差不是标准差
记忆口诀：
  • "均匀 → 长度，指数 → 时间，正态 → 钟形"
  • "正态标准化：减 $\mu$ 除 $\sigma$"
  • "3$\sigma$ 原则：$\pm\sigma=68\%, \pm 2\sigma=95\%, \pm 3\sigma=99.7\%$"
  • "指数无记忆性：$P(X>s+t|X>s) = P(X>t)$"

六、真题套路 · 二级结论 · 速算技巧

识别连续分布的速查

  • 等可能 / 均匀：$U(a,b)$，$E=(a+b)/2, D=(b-a)^2/12$
  • 到达 / 寿命时间间隔：$E(\lambda)$，$E=1/\lambda, D=1/\lambda^2$
  • 测量误差 / 自然现象：$N(\mu,\sigma^2)$

必背二级结论

  1. $E, D$ 总表：$U(a,b)$ → $(a+b)/2, (b-a)^2/12$；$E(\lambda)$ → $1/\lambda, 1/\lambda^2$；$N(\mu,\sigma^2)$ → $\mu, \sigma^2$
  2. 正态标准化：$X\sim N(\mu,\sigma^2)\Rightarrow Z = (X-\mu)/\sigma\sim N(0,1)$
  3. 正态对称：$\Phi(-x) = 1-\Phi(x)$；$u_{1-\alpha} = -u_\alpha$
  4. $3\sigma$ 原则：$P(|X-\mu|<\sigma) = 68\%$；$<2\sigma=95\%$；$<3\sigma=99.7\%$
  5. 分位数：$u_{0.05}=1.645, u_{0.025}=1.96, u_{0.01}=2.33, u_{0.005}=2.575$
  6. 指数无记忆：$P(X>s+t\mid X>s) = P(X>t)$（连续唯一！）
  7. $n$ 个独立 $E(\lambda)$ 取 min：$\sim E(n\lambda)$（重要！）
  8. 指数与 Poisson 关系：Poisson 流的间隔时间服从 $E(\lambda)$
  9. $E|X|$（$X\sim N(0,1)$）：$\sqrt{2/\pi}\approx 0.798$（必背）
  10. $X\sim N(0,1)\Rightarrow X^2\sim\chi^2(1)$

速算与解题技巧

  1. 正态概率计算流程：标准化 → 化为 $\Phi(\cdot)-\Phi(\cdot)$ → 用对称性 → 查表
  2. "求 $n$ 使概率 $\geq$ 某值"：用 $\Phi^{-1}(c) = z^*$ 反查
  3. 指数分布的 $P(X>a)$：直接 $e^{-\lambda a}$，不用积分
  4. 密度归一化求常数 $c$：$\int_{-\infty}^{+\infty}cf(x)\dd x = 1$
  5. $P(a：直接积分 $\int_a^b f\dd x$ 或 $F(b)-F(a)$
  6. 正态的 $E(X), D(X)$ 直接看参数：$N(\mu,\sigma^2)$ 中 $\mu$ 是均值，$\sigma^2$ 是方差

常错"小坑"清单

  • 正态标准化分母用 $\sigma$（不是 $\sigma^2$）
  • $\Phi(-x) = 1-\Phi(x)$ 忘减负数情况
  • 指数分布参数：$E(\lambda)$ 中 $\lambda$ 是率，$E(X) = 1/\lambda$
  • $N(\mu,\sigma^2)$ 中第二参数是方差不是标准差（教材约定）
  • 无记忆性：离散是几何，连续是指数
  • 连续型 $P(X=a) = 0$ 但事件未必不发生
