题型 A：全概率 + Bayes（每年题 13）

题 A1（23-24-2 第 13 题 ★★★★★）：甲乙丙三门炮独立射击，命中率 0.4 / 0.5 / 0.7。若仅一门击中，摧毁概率 0.2；两门击中 0.6；三门全中 1。
  1. 求目标被摧毁的概率。
  2. 已知目标被摧毁，恰两门击中的概率。
解

设 $B_k$ = "恰 $k$ 门击中"，$A$ = "目标被摧毁"。

$P(B_0) = 0.6\cdot 0.5\cdot 0.3 = 0.09$

$P(B_1) = 0.4\cdot 0.5\cdot 0.3+0.6\cdot 0.5\cdot 0.3+0.6\cdot 0.5\cdot 0.7 = 0.06+0.09+0.21 = 0.36$

$P(B_2) = 0.4\cdot 0.5\cdot 0.3+0.4\cdot 0.5\cdot 0.7+0.6\cdot 0.5\cdot 0.7 = 0.06+0.14+0.21 = 0.41$

$P(B_3) = 0.4\cdot 0.5\cdot 0.7 = 0.14$

(1) 全概率：$P(A) = 0\cdot 0.09 + 0.2\cdot 0.36 + 0.6\cdot 0.41 + 1\cdot 0.14 = 0.072 + 0.246 + 0.14 = 0.458$

(2) Bayes：$P(B_2\mid A) = \dfrac{P(B_2)P(A\mid B_2)}{P(A)} = \dfrac{0.41\cdot 0.6}{0.458} = \dfrac{0.246}{0.458}\approx 0.537$

题 A2（22-23-2 第 13 题）：某地驾驶员分新手（25%）、熟练（45%）、老司机（30%）三类，年事故概率分别为 0.04 / 0.02 / 0.01。
  1. 任一驾驶员一年内出事故的概率。
  2. 已知出事故，求是新手的概率。
解

$P(A) = 0.25\cdot 0.04 + 0.45\cdot 0.02 + 0.3\cdot 0.01 = 0.01 + 0.009 + 0.003 = 0.022$

$P(\text{新手}\mid A) = \dfrac{0.25\cdot 0.04}{0.022} = \dfrac{0.01}{0.022}\approx 0.455$

模板：① 划分 $\{B_i\}$（验证两两互斥且并为 $\Omega$）；② 列已知 $P(B_i),\,P(A\mid B_i)$；③ 全概率 $P(A)=\sum P(B_i)P(A\mid B_i)$；④ Bayes 反推。

    题 C3（极值经典，指数串并联）：$n$ 个独立元件寿命 $\sim E(\lambda)$，求串联和并联的寿命分布。
    解

    串联（min）：$F_N(z)=1-(1-F(z))^n=1-e^{-n\lambda z}$，即 $N\sim E(n\lambda)$。

    并联（max）：$F_M(z)=F(z)^n=(1-e^{-\lambda z})^n$，无简单形式。

    结论：$n$ 个 i.i.d. $E(\lambda)$ 取 min 仍是指数分布，参数变为 $n\lambda$。

    题型 D：Chebyshev + CLT 双胞胎（每年题 16）

    题 D1（23-24-2 第 16 题）：某品牌家用电脑年故障率 0.1，独立。某地区 400 户使用。
    1. 用 Chebyshev 估计"故障数在 30~50 之间"的概率下界。
    2. 用 CLT 估计同一概率。
    解

    $S\sim B(400,0.1)$，$E(S)=40,\,D(S)=36$，$\sigma=6$。事件 $30\leq S\leq 50$ 即 $|S-40|\leq 10$。

    (1) Chebyshev：$P(|S-40|<10)\geq 1-\dfrac{36}{100}=0.64$，下界 0.64。

    (2) CLT：$Z=\dfrac{S-40}{6}\approx N(0,1)$。

    $$P(|S-40|<10)\approx P(|Z|<10/6)=2\Phi(1.667)-1\approx 2\cdot 0.952-1=0.904$$

    对比：Chebyshev 给出粗下界 0.64，CLT 给出精确值约 0.90。CLT 更准。

    题 D2（CLT 反查 n）：每次测量误差 $\sim U(-1,1)$ 独立。希望 $n$ 次平均误差落入 $[-0.1,0.1]$ 的概率不低于 0.95，求最少 $n$。
    解

    $E=0,\,D=1/3,\,\sigma=1/\sqrt 3$。$\bar X\approx N(0,1/(3n))$。

    $$P(|\bar X|<0.1)\approx 2\Phi(0.1\sqrt{3n})-1\geq 0.95\Rightarrow\Phi(0.1\sqrt{3n})\geq 0.975$$

    查表 $\Phi^{-1}(0.975)=1.96$。$0.1\sqrt{3n}\geq 1.96\Rightarrow n\geq 1.96^2/(0.01\cdot 3)\approx 128.05$，取 $n=129$。

    题型 E：估计量评价（题 17）

    题 E1（23-24-2 第 17 题 ★★★★★，连续 3 套都考）：$X\sim N(0,\sigma^2)$ 简单样本 $X_1,\ldots,X_n$。对以下三个统计量进行 (a) 无偏性判断 (b) 矫正成无偏估计 (c) 比较矫正后的方差。 $$S_1^2=\frac{1}{n}\sum X_i^2,\quad S_2^2=\frac{1}{n}\sum(X_i-\bar X)^2,\quad S_3^2=\bar X^2$$
    解

    (a)+(b) 无偏性：

    • $E(S_1^2)=\dfrac{1}{n}\sum E(X_i^2)=\dfrac{1}{n}\cdot n\sigma^2=\sigma^2$ → 无偏（$\mu=0$）
    • $E(S_2^2)=\dfrac{n-1}{n}\sigma^2$ → 有偏，矫正 $\hat S_2^2=\dfrac{n}{n-1}S_2^2$
    • $E(S_3^2)=E(\bar X^2)=D(\bar X)+(E\bar X)^2=\sigma^2/n$ → 有偏，矫正 $\hat S_3^2=n\bar X^2$

    (c) 方差比较（用 $X_i^2/\sigma^2\sim\chi^2(1)$，$E(X_i^2)=\sigma^2,\,D(X_i^2)=2\sigma^4$）：

    • $D(S_1^2)=\dfrac{1}{n^2}\cdot n\cdot 2\sigma^4=\dfrac{2\sigma^4}{n}$
    • $\hat S_2^2 = \dfrac{n}{n-1}S_2^2 = S^2$（标准样本方差），由 $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ 得 $D(\hat S_2^2)=D(S^2)=\dfrac{2\sigma^4}{n-1}$
    • $\bar X\sim N(0,\sigma^2/n)\Rightarrow n\bar X^2/\sigma^2\sim\chi^2(1)$，$D(n\bar X^2)=\sigma^4\cdot 2=2\sigma^4$

    排序（小→大 即 好→差）：$D(S_1^2)

    关键结论：$E(\bar X^2)=\sigma^2/n+\mu^2$。这是近 3 套都在反复考的核心公式！

    题型 F：矩估计 + MLE（题 18）

    题 F1（20-21-2 第 18 题，带平移指数）：$X$ 密度 $f(x;\alpha,\beta)=\beta e^{-\beta(x-\alpha)}$，$x\geq\alpha$。求 $\alpha,\beta$ 的矩估计和 MLE。
    解

    矩估计：$X-\alpha\sim E(\beta)$，$E(X)=\alpha+1/\beta,\,D(X)=1/\beta^2$。

    令 $\mu_1=\bar X, \mu_2-\mu_1^2=S_n^2$：

    • $\hat\beta=1/S_n$（$S_n^2=\dfrac{1}{n}\sum(X_i-\bar X)^2$）
    • $\hat\alpha=\bar X-S_n=\bar X-1/\hat\beta$

    MLE：似然

    $$L(\alpha,\beta)=\beta^n e^{-\beta\sum(X_i-\alpha)}\mathbf 1_{\alpha\leq\min X_i}$$

    对 $\alpha$：$L$ 关于 $\alpha$ 单调递增（指数项 $\beta n\alpha$ 是增），但受约束 $\alpha\leq\min X_i$，故 $\hat\alpha_{\text{MLE}}=\min X_i$（边界 MLE！）。

    对 $\beta$：固定 $\alpha=\hat\alpha$，$\ln L=n\ln\beta-\beta\sum(X_i-\hat\alpha)$，$\partial_\beta=0$ 得 $\hat\beta_{\text{MLE}}=\dfrac{1}{\bar X-\min X_i}$。

    易错：定义域含 $\alpha$ 时 MLE 必须看单调性而不是求导！

    题 F2（指数分布矩 + MLE）：$X\sim E(\lambda)$ 样本，求 $\lambda$ 估计。
    解

    矩：$E(X)=1/\lambda=\bar X\Rightarrow\hat\lambda=1/\bar X$。

    MLE：$L=\lambda^n e^{-\lambda\sum X_i}$，$\ln L=n\ln\lambda-\lambda n\bar X$，$\hat\lambda=1/\bar X$。

    结论：两种方法给出相同结果。

    题 G1（23-24-2 第 19 题 ★★★★★，P 值 + 经典法 + 频数表）：车轴直径 $X\sim N(\mu,\sigma^2)$。要求均值 $\mu=4.0$、方差 $\sigma^2\leq 0.1$。25 件样本频数表给出。

    选择题高频考点

    选 1（不相关 vs 独立反例，14-15-2 第 1 题）：$(X,Y)$ 在单位圆内均匀分布。判断：
    • ① $X,Y$ 不相关
    • ② $X,Y$ 相互独立
    • ③ $D(X-Y)=D(X)-D(Y)$
    • ④ $E(XY)=E(X)E(Y)$
    正确的是 ___。
    分析

    ① $E(X)=E(Y)=0$（对称），$E(XY)=\iint_{x^2+y^2\leq 1}xy\dfrac{1}{\pi}\dd x\dd y$，被积奇函数 → 0。所以 $\Cov=0$，不相关。

    ② $f(x,y)=1/\pi$，$f_X(x)=\dfrac{2\sqrt{1-x^2}}{\pi}$，$f_X\cdot f_Y\neq 1/\pi$，不独立。

    ③ 独立时才有 $D(X-Y)=D(X)+D(Y)$（同号！）；不独立时 $D(X-Y)=D(X)+D(Y)-2\Cov(X,Y)$。但即便 $\Cov=0$，仍是 $D(X)+D(Y)$，不是 $D(X)-D(Y)$。错。

    ④ $E(XY)=0=E(X)E(Y)$，对。

    正确：①④

    选 2（密度偶函数性质）：$X$ 密度是偶函数，分布函数 $F(x)$。下列哪些正确？
    • ① $F(x)=F(-x)$
    • ② $F(-x)=1-F(x)$
    • ③ $P(|X|\leq x)=2F(x)-1$（$x\geq 0$）
    • ④ $F(0)=1/2$
    分析

    ① 错。$F$ 单调增不可能是偶函数。

    ② 对。由密度偶函数，$P(X<-x)=P(X>x)=1-F(x)$，又 $P(X<-x)=F(-x-0)=F(-x)$（连续型）。

    ③ 对。$P(|X|\leq x)=F(x)-F(-x)=F(x)-(1-F(x))=2F(x)-1$。

    ④ 对。由②取 $x=0$：$F(0)=1-F(0)\Rightarrow F(0)=1/2$。

    正确：②③④

    • (A) $\dfrac{1}{2}X_1+\dfrac{1}{2}X_2$，$D=\sigma^2/2$
