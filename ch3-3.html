3.3-3.4 随机变量的独立性 & 多维随机变量 ⭐⭐

本节真题考频：14 套真题命中 9 套。选择题 2-3 题，常考"判断独立"。
典型出题：可分离 + 矩形支撑判独立 · 二维正态 $\rho = 0$ ⇔ 独立 · 不相关 ≠ 独立反例。

一、独立性的判定 ⭐⭐

⭐ 定义

$X, Y$ 相互独立 $\Leftrightarrow$ 对一切 $(x, y)$：

$$F(x, y) = F_X(x)F_Y(y)$$

等价形式：

  • 离散：$p_{ij} = p_{i\cdot}p_{\cdot j}$（一切 $i, j$）
  • 连续：$f(x, y) = f_X(x)f_Y(y)$（连续点处）
⭐ 可分离判别法（实战常用）

若 $f(x, y) = r(x)g(y)$ 且支撑为矩形（$x$ 和 $y$ 的范围互不约束），则 $X, Y$ 独立。

关键：支撑必须是矩形！

  • $f(x, y) = e^{-x-y},\,x, y > 0$ → 支撑 $(0, \infty)\times(0, \infty)$ 矩形 → 独立 ✓
  • $f(x, y) = 2,\,0 < x < y < 1$ → 支撑三角形 → 不独立（虽然 $f = 2$ 看似可拆，但支撑非矩形）

二、二维正态的独立性 ⭐

$(X, Y)\sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$：

$$X, Y\text{ 独立}\Leftrightarrow\rho = 0$$

仅在此分布下三者等价！一般 "不相关 ≠ 独立"。

三、独立性的传递

$X, Y$ 独立 $\Rightarrow$ 对任意 Borel 函数 $u, v$：$u(X)$ 与 $v(Y)$ 也独立。

用途：例如 $X, Y$ 独立则 $X^2, Y^2$ 独立、$\sin X, e^Y$ 独立、$|X|, Y^3$ 独立。

四、$n$ 维随机变量

$n$ 维联合分布函数 $F(x_1, \ldots, x_n) = P(X_1\leq x_1, \ldots, X_n\leq x_n)$。

$n$ 维相互独立：

$$F(x_1, \ldots, x_n) = \prod_{i=1}^n F_{X_i}(x_i)$$

等价于 $f = \prod f_{X_i}$（连续）或 $p = \prod p_i$（离散）。

性质：相互独立 ⇒ 任意子集独立，各自函数独立。

五、典型例题

题 ★（指数分布积，可分离）：$f(x, y) = 6e^{-2x-3y},\,x, y > 0$。判断独立性。
解

$f$ 可拆 $f = 2e^{-2x}\cdot 3e^{-3y}$，支撑 $(0, \infty)^2$ 是矩形 → 独立。

所以 $X\sim E(2),\,Y\sim E(3)$。

题 ★★（区域非矩形）：$(X, Y)$ 在 $D = \{(x, y):y^2\leq x\leq 1\}$ 上均匀分布。判断独立。
解

$D$ 面积 $= \int_{-1}^1(1-y^2)\dd y = 4/3$，$f(x, y) = 3/4$（似乎可拆）。

$f_X(x) = \int_{-\sqrt x}^{\sqrt x}\dfrac{3}{4}\dd y = \dfrac{3\sqrt x}{2}$；$f_Y(y) = \int_{y^2}^1\dfrac{3}{4}\dd x = \dfrac{3(1-y^2)}{4}$。

$f_X\cdot f_Y = \dfrac{9\sqrt x(1-y^2)}{8}\neq\dfrac{3}{4} = f$，不独立。

本质：支撑 $D$ 不是矩形，$x, y$ 互相约束。

题（密度看似 $r(x)g(y)$ 但支撑非矩形）：$(X, Y)$ 联合密度 $f(x, y) = 8xy,\,0 < x < y < 1$。判断独立。
解

$f = 8xy$ 形式上可拆为 $8x\cdot y$，但支撑 $\{x < y\}$ 不是矩形 → 不独立。

验证：$f_X(x) = \int_x^1 8xy\dd y = 4x(1-x^2),\,f_Y(y) = \int_0^y 8xy\dd x = 4y^3$。

$f_X\cdot f_Y = 16xy(1-x^2)y^3\neq 8xy$，确认不独立。

六、易错点清单

  • "$f$ 可拆 → 独立"是错的！必须先看支撑是否为矩形
  • "$\rho = 0$ → 独立"仅对二维正态成立
  • 多事件独立和两两独立的混淆（参见 1.4）
  • 独立性的传递：$X\perp Y \Rightarrow u(X)\perp v(Y)$，经常忘
  • 判断独立要验证所有 $(x, y)$ 点（找一个反例就够说明不独立）
记忆口诀：
  • "独立 = 可分离 + 矩形支撑"（两个条件缺一不可）
  • "独立 $\Rightarrow$ 不相关；反向只在二维正态"
  • "独立可传递到函数"（$X\perp Y\Rightarrow X^2\perp Y^3$）

七、真题套路 · 二级结论 · 速算技巧

判独立的快速方法

  1. 第一步看支撑：是否为矩形（$x$ 范围与 $y$ 范围互不约束）？
  2. 支撑非矩形 → 不独立（无需验证密度）
  3. 支撑矩形 → 验密度是否可拆 $f = r(x)g(y)$
  4. 二维正态特例：直接看 $\rho$ 是否为 0

必背二级结论

  1. 独立 ⇔ $f(x,y) = f_X(x)f_Y(y)$（连续型）
  2. 独立 ⇔ $p_{ij} = p_{i\cdot}p_{\cdot j}$（离散型）
  3. 可分离 + 矩形支撑 ⇔ 独立（必须两个条件！）
  4. 二维正态独立 ⇔ $\rho = 0$（仅此分布！）
  5. 独立传递到函数：$X\perp Y\Rightarrow u(X)\perp v(Y)$
  6. 独立 + 同分布：i.i.d.（统计学基础）
  7. $n$ 维独立 ⇒ 任意子集独立
  8. $n$ 维独立 ⇒ 联合密度 = 边缘乘积

速算与解题技巧

  1. 先看支撑：非矩形立刻判为不独立，省时
  2. 独立时 $f_X f_Y$ 表达式应等于联合 $f$，对应位置写出对比
  3. 二维正态参数 $\rho = 0$，立刻独立
  4. 独立的应用：$E(XY) = E(X)E(Y)$，$D(X+Y) = D(X)+D(Y)$

常错"小坑"清单

  • "$f$ 可拆 → 独立" 错！必须先看支撑
  • $\rho = 0$ → 独立仅对二维正态
  • 独立可传递到函数，经常忘
  • 多事件独立和两两独立的混淆（见 1.4）

八、真题原型（不相关 ≠ 独立 · 经典陷阱）

题 ★★★★ 22-23-2 第 10 题（四命题判断，独立性压轴陷阱）：已知 $X\sim N(\mu,\sigma^2)$、$Y\sim N(\mu,\sigma^2)$，相关系数 $\rho_{X,Y}=-0.3$。注意：只给两个边缘正态，没说 $(X,Y)$ 联合正态。判断下列命题对错：
  1. $(X,Y)$ 服从二维正态分布；
  2. $\D(X-2Y)=6.2\sigma^2$；
  3. $X+Y$ 与 $X-Y$ 不相关；
  4. $X+Y$ 与 $X-Y$ 相互独立。
解

① 错：边缘都正态 $\nRightarrow$ 联合正态（可构造边缘正态但联合非正态的反例），故不能断定 $(X,Y)$ 二维正态。

② 对：$\D(X-2Y)=\D X+4\D Y-2\cdot 2\,\Cov(X,Y)=\sigma^2+4\sigma^2-4\rho\sigma^2=5\sigma^2-4(-0.3)\sigma^2=6.2\sigma^2$。

③ 对：$\Cov(X+Y,X-Y)=\D(X)-\D(Y)=\sigma^2-\sigma^2=0$，故不相关。只要边缘同方差即成立，不需要正态。

④ 错：独立比不相关强，需要 $(X,Y)$ 联合正态才能由"不相关"推出"独立"；而①已说明联合不一定正态，故 $X+Y\perp X-Y$ 无法保证。

正确命题为 ②③（选 D）。

核心教训：$\rho=0\Rightarrow$ 独立 这一步只在确认 $(X,Y)$ 联合正态时才成立；"两个边缘各自正态"不够！

九、必背块 · 独立性判据

⭐ 一页背全
  • 独立 $\Leftrightarrow F(x,y)=F_X(x)F_Y(y)\Leftrightarrow f(x,y)=f_X(x)f_Y(y)$（连续）$\Leftrightarrow p_{ij}=p_{i\cdot}p_{\cdot j}$（离散）。
  • 实战判据：独立 $\Leftrightarrow$ 密度可分离 $f=r(x)g(y)$ 且支撑为矩形（两条件缺一不可）。支撑非矩形（如 $x
  • 独立 $\Rightarrow$ 不相关（$\Cov=0$）；反向仅二维正态成立。一般"不相关 $\nRightarrow$ 独立"。
  • 二维正态：独立 $\Leftrightarrow$ 不相关 $\Leftrightarrow\rho=0$（仅此分布三者等价）。
  • 传递性：$X\perp Y\Rightarrow u(X)\perp v(Y)$（如 $X^2\perp Y^3$、$|X|\perp e^Y$）。
  • 独立时：$\E(XY)=\E X\,\E Y$，$\D(X\pm Y)=\D X+\D Y$。
  • $n$ 维相互独立 $\Rightarrow$ 任意子集独立、各自函数独立、联合 $=$ 边缘乘积。
  • 边缘正态 $\nRightarrow$ 联合正态（22-23-2[10] 陷阱）。
