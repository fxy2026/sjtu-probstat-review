6.1 数理统计的基本概念 ⭐

本节真题考频：每年选择/填空 1-2 道。$\bar X, S^2$ 性质是后续 6.2、7、8 章基础。
典型出题：判断哪些是统计量 · $E(\bar X), D(\bar X), E(S^2)$ · 分位数定义。

一、总体、样本、统计量

  • 总体：研究对象全体（视为随机变量 $X$，其分布为总体分布）
  • 个体：$X$ 的一次取值
  • 样本：从总体抽取的 $n$ 个个体 $(X_1, \ldots, X_n)$，样本容量 $n$
  • 简单随机样本（i.i.d.）：$X_i$ 与 $X$ 同分布且相互独立
简单样本的联合分布

$F_X$ 是总体分布函数：

$$F(x_1, \ldots, x_n) = \prod_{i=1}^n F_X(x_i),\quad f(x_1, \ldots, x_n) = \prod_{i=1}^n f_X(x_i)$$
⭐ 统计量定义

样本 $(X_1, \ldots, X_n)$ 的不含未知参数的可测函数 $g(X_1, \ldots, X_n)$ 称为统计量。

关键：不能含未知参数！

例：$X\sim N(\mu, \sigma^2),\,\mu, \sigma^2$ 未知：

  • $\bar X$ 是统计量 ✓
  • $S^2$ 是统计量 ✓
  • $\dfrac{\bar X-\mu}{\sigma}$ 不是统计量（含 $\mu, \sigma$）

二、常用统计量及其性质

$$\bar X = \dfrac{1}{n}\sum_{i=1}^n X_i\quad\text{样本均值}$$ $$S^2 = \dfrac{1}{n-1}\sum_{i=1}^n(X_i-\bar X)^2\quad\text{样本方差（分母 $n-1$）}$$ $$S_n^2 = \dfrac{1}{n}\sum_{i=1}^n(X_i-\bar X)^2 = \dfrac{n-1}{n}S^2\quad\text{样本二阶中心矩}$$ $$M_k = \dfrac{1}{n}\sum_{i=1}^n X_i^k\quad\text{样本 $k$ 阶（原点）矩}$$
⭐ 期望/方差关键结论（对任意分布都成立！）
  • $E(\bar X) = \mu$
  • $D(\bar X) = \sigma^2/n$
  • $E(S^2) = \sigma^2$（无偏！ 这就是分母用 $n-1$ 的原因）
  • $E(S_n^2) = \frac{n-1}{n}\sigma^2$（有偏）
  • $M_k\xrightarrow{P}E(X^k)$（依概率收敛）
  • $E(\bar X^2) = \sigma^2/n+\mu^2$（连考 3 套关键公式）
$E(S^2) = \sigma^2$ 的证明： $$E(S^2) = \dfrac{1}{n-1}\left[E\!\left(\sum X_i^2\right)-nE(\bar X^2)\right] = \dfrac{1}{n-1}\left[n(\sigma^2+\mu^2)-n(\sigma^2/n+\mu^2)\right] = \dfrac{n\sigma^2-\sigma^2}{n-1} = \sigma^2$$ "分母 $n-1$ 而不是 $n$"就是为了让 $S^2$ 无偏。

三、顺序统计量与分位数

顺序统计量：把 $(X_1, \ldots, X_n)$ 从小到大排序得 $X_{(1)}\leq X_{(2)}\leq\cdots\leq X_{(n)}$。

  • 最小 $X_{(1)} = \min X_i$；最大 $X_{(n)} = \max X_i$
  • 样本中位数 $\tilde X$：奇数 $n$ 取 $X_{((n+1)/2)}$；偶数 $n$ 取中间两个的平均
  • 样本极差 $R = X_{(n)}-X_{(1)}$
⭐ 分位数（必背！）

上侧 $\alpha$ 分位数：$P(X > x_\alpha) = \alpha$（右尾概率 = $\alpha$）

标准正态：

$\alpha$0.100.050.0250.010.005
$u_\alpha$1.281.6451.962.332.575

对称性：$u_{1-\alpha} = -u_\alpha$（因为标准正态密度是偶函数）

四、典型例题

题 ★：总体 $X\sim N(52, 6.3^2)$，$n = 36$。求 $P(50.8<\bar X<53.8)$。
解

$\bar X\sim N(52, 6.3^2/36) = N(52, 1.1025)$，$\sigma_{\bar X} = 1.05$。

$$P(50.8<\bar X<53.8) = \Phi\!\left(\dfrac{1.8}{1.05}\right)-\Phi\!\left(\dfrac{-1.2}{1.05}\right) = \Phi(1.71)-\Phi(-1.14)\approx 0.829$$

五、考试要点

本节常考：
  • 判断"哪些是统计量"（不含未知参数）
  • $E(\bar X), D(\bar X), E(S^2)$ 直接套用
  • 样本 $k$ 阶矩与总体 $k$ 阶矩的关系（矩估计准备）
  • 分位数定义与对称性
易错：
  • $S^2$ 用 $n-1$ 才无偏；$S_n^2$ 用 $n$ 有偏
  • 统计量不能含未知参数
  • $\bar X$ 是 $\mu$ 的任意分布下的无偏估计
  • $D(\bar X) = \sigma^2/n$，分母是 $n$（不是 $\sqrt n$）
记忆口诀：
  • "$\bar X$ 估 $\mu$，$S^2$ 估 $\sigma^2$，都无偏"
  • "$D(\bar X) = \sigma^2/n$；$E(\bar X^2) = \sigma^2/n + \mu^2$"
  • "统计量 = 不含未知参数的样本函数"
  • "上 α 分位数：$P(X > x_\alpha) = \alpha$"

六、真题套路 · 二级结论 · 速算技巧

必背二级结论

  1. $E(\bar X) = \mu$（任意分布）
  2. $D(\bar X) = \sigma^2/n$（任意分布）
  3. $E(S^2) = \sigma^2$（任意分布无偏）
  4. $E(S_n^2) = \frac{n-1}{n}\sigma^2$（有偏）
  5. $E(\bar X^2) = \sigma^2/n+\mu^2$（连考 3 套关键！）
  6. $M_k\xrightarrow{P}E(X^k)$（矩估计基础）
  7. 简单样本联合密度：$f = \prod f_X(x_i)$
  8. 统计量 = 不含未知参数的样本函数
  9. 上 α 分位数：$P(X>x_\alpha) = \alpha$；$u_{1-\alpha} = -u_\alpha$
  10. 顺序统计量：$X_{(1)}\leq X_{(2)}\leq\cdots\leq X_{(n)}$

速算与解题技巧

  1. 判断统计量：是否含未知参数
  2. $\bar X, S^2$ 的期望直接背
  3. $D(\bar X) = \sigma^2/n$ 用于 CLT 标准化
  4. 查表分位数 $u_{0.025} = 1.96, u_{0.05} = 1.645, u_{0.01} = 2.33$
  5. 正态总体下 $\bar X\sim N(\mu, \sigma^2/n)$ 严格

常错"小坑"清单

  • 统计量不能含未知参数
  • $S^2$ 用 $n-1$ 才无偏
  • $D(\bar X) = \sigma^2/n$，分母 $n$（不是 $\sqrt n$）
  • $E(\bar X^2)$ 漏 $\mu^2$ 项
  • 分位数 $u_{1-\alpha} = -u_\alpha$（对称性）
