4.1 数学期望 ⭐⭐⭐

本节真题考频：14/14 套真题命中（100%）。每年大题工具，作为题 14-19 的基础。
典型出题：LOTUS · 示性函数法（配对期望，hat-matching）· 7 大分布期望直接套 · $E(e^{aX})$ 矩母函数。

一、定义

离散型：$E(X) = \sum_k x_k p_k$（绝对收敛 $\sum|x_k|p_k<\infty$）

连续型：$E(X) = \int_{-\infty}^{+\infty}xf(x)\dd x$（绝对收敛 $\int|x|f(x)\dd x<\infty$）

绝对收敛要求必不可少！否则期望不存在。
反例（Cauchy 分布）：$f(x) = \dfrac{1}{\pi(1+x^2)}$。期望积分 $\int|x|/(\pi(1+x^2))\dd x$ 发散，期望不存在。

二、LOTUS（随机变量函数的期望）

⭐ Law Of The Unconscious Statistician

对 $Y = g(X)$，不需要先求 $Y$ 的分布：

$$E[g(X)] = \sum_k g(x_k)p_k\quad\text{或}\quad\int g(x)f(x)\dd x$$

二维：

$$E[g(X, Y)] = \sum_{i,j}g(x_i, y_j)p_{ij}\quad\text{或}\quad\iint g(x, y)f(x, y)\dd x\dd y$$
例：$X\sim P(\lambda)$，求 $E(3^X)$。
解
$$E(3^X) = \sum_{k=0}^\infty 3^k\dfrac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda}\sum\dfrac{(3\lambda)^k}{k!} = e^{2\lambda}$$

三、期望的性质（必背！）

  1. $E(C) = C$（常数）
  2. $E(aX+b) = aE(X)+b$
  3. 线性性：$E(X+Y) = E(X)+E(Y)$（无需独立！）
  4. $X, Y$ 独立 $\Rightarrow E(XY) = E(X)E(Y)$（反向不真）
  5. $|E(X)|\leq E(|X|)$
⭐ 示性函数法（解题神器！）

对事件 $A$ 定义示性函数 $I_A = \begin{cases}1,&A\text{ 发生}\\0,&\text{否则}\end{cases}$

则 $E(I_A) = P(A)$。

用法：把"复杂计数随机变量"分解为示性函数求和，利用 $E$ 的线性性。

题 ★★（空盒数期望）：4 球随机独立放入 4 盒，求空盒数 $X$ 的期望。
解

令 $X_i = I_{\{\text{盒 }i\text{ 空}\}}$，$X = X_1+X_2+X_3+X_4$。

$P(X_i = 1) = (3/4)^4 = 81/256$。所以 $E(X) = 4\cdot 81/256 = 81/64$。

若直接列分布律会非常麻烦，示性函数法瞬间秒杀。

题 ★★（hat-matching，多年真题原型）：$n$ 个球编号放入 $n$ 个盒子（一一对应）。配对数 $X$ 的期望与方差。
解

$X = \sum X_i$，$X_i$ 是"第 $i$ 个盒配对"的示性。

$P(X_i = 1) = 1/n$，$E(X) = n\cdot 1/n = 1$。

$E(X_iX_j) = P(X_i = X_j = 1) = \dfrac{1}{n(n-1)}$（$i\neq j$）。

$E(X^2) = \sum E(X_i^2)+\sum_{i\neq j}E(X_iX_j) = n\cdot\dfrac{1}{n}+n(n-1)\cdot\dfrac{1}{n(n-1)} = 2$。

$D(X) = 2-1 = 1$。$E(X) = D(X) = 1$，与 $n$ 无关！

这是 hat-matching 标志性结论，多年压轴题都会用。

真题原型 ★★（几何分布期望 · LOTUS 反向用）：重复独立试验，每次成功概率 $p$，$X$ 为首次成功所需次数（$X\sim G(p)$）。求 $E(X)$，并求 $E(2^{-X})$（设 $p$ 使级数收敛）。
解

(1) $E(X)$：$E(X)=\sum_{k=1}^{\infty}k(1-p)^{k-1}p$。令 $q=1-p$，利用 $\sum_{k\ge 1}kq^{k-1}=\dfrac{1}{(1-q)^2}$，得 $E(X)=p\cdot\dfrac{1}{p^2}=\dfrac1p$。

(2) LOTUS：$E(2^{-X})=\sum_{k=1}^{\infty}2^{-k}q^{k-1}p=\dfrac{p}{q}\sum_{k\ge1}\Big(\dfrac q2\Big)^k=\dfrac pq\cdot\dfrac{q/2}{1-q/2}=\dfrac{p}{2-q}=\dfrac{p}{1+p}$。

验证：$p=1$ 时 $X\equiv1$，$E(2^{-X})=1/2=\dfrac{1}{1+1}$ ✓。这是"识别分布 + LOTUS 直接对级数求和"的标准压轴步骤。

四、七大分布期望总表（必背！）

分布参数$E(X)$
0-1$p$$p$
$B(n, p)$$n, p$$np$
$P(\lambda)$$\lambda$$\lambda$
$G(p)$$p$$1/p$
$U(a, b)$$a, b$$(a+b)/2$
$E(\lambda)$$\lambda$$1/\lambda$
$N(\mu, \sigma^2)$$\mu, \sigma^2$$\mu$
$\chi^2(n)$$n$$n$

五、关键推导（满分笔记）

二项分布 $E(X) = np$ 的推导：

$X = X_1 + \cdots + X_n$，每 $X_i\sim B(1, p)$，$E(X_i) = p$。

由线性性 $E(X) = nE(X_i) = np$。用示性函数法 1 行搞定。

Poisson $E(X) = \lambda$ 的推导： $$E(X) = \sum_{k=0}^\infty k\dfrac{\lambda^k e^{-\lambda}}{k!} = e^{-\lambda}\sum_{k=1}^\infty\dfrac{\lambda^k}{(k-1)!} = \lambda e^{-\lambda}\sum_{j=0}^\infty\dfrac{\lambda^j}{j!} = \lambda e^{-\lambda}\cdot e^\lambda = \lambda$$
正态 $E(X) = \mu$ 的推导：见 ch2-3，用变量代换 $y = x-\mu$ 后奇偶性即得。
指数 $E(X) = 1/\lambda$ 的推导： $$E(X) = \int_0^\infty x\lambda e^{-\lambda x}\dd x = \dfrac{1}{\lambda}\quad(\text{分部积分})$$

六、易错点清单

  • 必须绝对收敛，否则期望不存在（Cauchy 分布陷阱）
  • $E(XY) = E(X)E(Y)$ 仅独立时成立，不能乱用
  • $E[g(X)]\neq g(E(X))$（除 $g$ 线性外）
  • $E(X^2)\neq[E(X)]^2$ —— "平方的期望" vs "期望的平方"
  • $E(X+Y) = E(X)+E(Y)$ 不需要独立（这条多人忘）
  • 用示性函数法求计数期望（配对数、空盒数、首达时间等）
  • 级数/积分求 $E$ 时先判收敛再换序：交换求和与积分次序、提常数前先确认绝对收敛，否则结论可能错
  • $E(3^X)$ 这类指数型不要硬展开：凑成已知分布的归一化级数（如 Poisson 的 $\sum (3\lambda)^k/k!=e^{3\lambda}$）一步到位
⭐ 必背速查（期望）
  • 定义：$E(X)=\sum_k x_kp_k$（离散）/ $\int x f(x)\dd x$（连续），均需绝对收敛
  • LOTUS：$E[g(X)]=\sum g(x_k)p_k$ 或 $\int g(x)f(x)\dd x$（不必先求 $g(X)$ 分布）
  • 线性性（免费，无需独立）：$E(aX+bY+c)=aE(X)+bE(Y)+c$
  • 独立才有：$X\perp Y\Rightarrow E(XY)=E(X)E(Y)$（反之不真）
  • 示性函数：$E(I_A)=P(A)$；计数量 $X=\sum I_{A_i}\Rightarrow E(X)=\sum P(A_i)$
  • 七大分布 $E$：0-1→$p$；$B(n,p)$→$np$；$P(\lambda)$→$\lambda$；$G(p)$→$1/p$；$U(a,b)$→$\frac{a+b}2$；$E(\lambda)$→$1/\lambda$；$N(\mu,\sigma^2)$→$\mu$；$\chi^2(n)$→$n$
  • hat-matching：$n$ 球归位配对数 $X$，$E(X)=1$（与 $n$ 无关）
  • $E|X|$（$X\sim N(0,\sigma^2)$）$=\sigma\sqrt{2/\pi}$
记忆口诀：
  • "$E$ 是线性算子，加减无障碍"
  • "$E(XY) = E(X)E(Y)$ 需要独立"
  • "示性函数 = $E(I_A) = P(A)$，计数神器"
  • "LOTUS：$E[g(X)] = \int g(x)f(x)\dd x$，无需求 $Y$ 分布"

七、真题套路 · 二级结论 · 速算技巧

常用计算技巧

  • LOTUS：$E[g(X)] = \int g(x)f(x)\dd x$ —— 不用求 $Y = g(X)$ 的分布！
  • 示性函数法：$X = \sum X_i$（$X_i = I_{A_i}$），$E(X) = \sum P(A_i)$
  • 独立性：$X\perp Y\Rightarrow E(XY) = E(X)E(Y)$
  • 分部积分：求 $E$ 涉及 $xe^{-\lambda x}$ 等

必背二级结论

  1. 七大分布期望：0-1→$p$；$B(n,p)$→$np$；$P(\lambda)$→$\lambda$；$G(p)$→$1/p$；$U(a,b)$→$(a+b)/2$；$E(\lambda)$→$1/\lambda$；$N(\mu,\sigma^2)$→$\mu$
  2. $\chi^2(n)$：$E = n, D = 2n$
  3. 线性性：$E(aX+bY+c) = aE(X)+bE(Y)+c$（无需独立）
  4. $E(XY) = E(X)E(Y)$：要独立或不相关
  5. 示性函数：$E(I_A) = P(A)$
  6. hat-matching：$n$ 个球放入 $n$ 个盒，配对数 $X$ 满足 $E(X) = 1, D(X) = 1$，与 $n$ 无关
  7. $E(e^{aX})$ 矩母函数：用于计算 $E(X^k)$
  8. Cauchy 分布期望不存在（$f = 1/(\pi(1+x^2))$）
  9. $E[g(X,Y)] = \iint g(x,y)f(x,y)\dd x\dd y$（二维 LOTUS）
  10. $E|X|$（$X\sim N(0,\sigma^2)$）：$\sigma\sqrt{2/\pi}$

速算与解题技巧

  1. 识别分布 → 直接套 $E$
  2. 计数期望用示性函数：空盒数、配对数、首次成功等
  3. $E(\sum X_i) = \sum E(X_i)$ 无需独立，先拆再算
  4. $E(X+a) = E(X)+a$；$E(aX) = aE(X)$，常数无关
  5. 对称分布的奇函数期望 = 0（如 $N(0,1)$ 的 $X^3$）
  6. $E(X)$ 不存在的判别：$\int|x|f(x)\dd x$ 是否收敛

常错"小坑"清单

  • $E(XY) = E(X)E(Y)$ 乱用：必须独立
  • $E[g(X)] \neq g(E(X))$（除 $g$ 线性外）
  • $E(X^2) \neq [E(X)]^2$
  • 绝对收敛要求：否则期望不存在
  • $E(X+Y)$ 不需要独立（线性性是免费的）
