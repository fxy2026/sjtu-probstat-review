5.3 中心极限定理（CLT）⭐⭐⭐

本节真题考频：14/14 套真题命中（100%！）。每年大题第 14 或 16 题（9 分），与 Chebyshev 联考。
典型出题：23-24-2 家庭电脑 400 户 · 23-24-1 维修 40 台 · 22-23-2 血型 1000 人 · 20-21-2 便利店 200 顾客 · 19-20-1 汽车通过 1000 辆。

一、Lindeberg-Lévy 中心极限定理（i.i.d.）

⭐ 经典 CLT（独立同分布）

设 $X_1, X_2, \ldots$ 是 i.i.d. 随机变量序列，$E(X_i) = \mu, D(X_i) = \sigma^2$ 存在（$0 < \sigma^2 < \infty$）。则当 $n$ 大时：

$$\dfrac{\sum_{i=1}^n X_i - n\mu}{\sqrt n\sigma}\xrightarrow{d}N(0, 1)$$

等价说法（实际应用中最常用！）：

$$\sum_{i=1}^n X_i\;\overset{\text{近似}}{\sim}\;N(n\mu, n\sigma^2),\quad\bar X_n\;\overset{\text{近似}}{\sim}\;N\!\left(\mu,\dfrac{\sigma^2}{n}\right)$$

二、De Moivre-Laplace CLT（二项 → 正态）

$Y_n\sim B(n, p)$，则

$$\dfrac{Y_n - np}{\sqrt{np(1-p)}}\xrightarrow{d}N(0, 1)$$

即 $Y_n\overset{\text{近似}}{\sim}N(np, np(1-p))$。

三选一判别表（不同近似的适用条件）：
  • $n$ 小（$n\leq 20$）：直接用二项分布
  • $n$ 大、$p$ 小、$np\leq 10$：用 Poisson 近似 $P(np)$
  • $n$ 大、$0.1 < p < 0.9$：用 正态近似 $N(np, np(1-p))$

三、CLT 标准解题流程（满分答题模板）

⭐ 五步法
  1. 识别 $\sum X_i$ 或 $\bar X_n$：$X_i$ 必须 i.i.d.
  2. 算 $\mu = E(X_i)$, $\sigma^2 = D(X_i)$（一定要写出来！）
  3. 标准化：$Z = \dfrac{\sum X_i - n\mu}{\sqrt n\sigma}$ 或 $Z = \dfrac{\bar X-\mu}{\sigma/\sqrt n}$
  4. $Z\approx N(0, 1)$，要求的概率转化为 $\Phi$ 的值
  5. 查标准正态表得最终值

四、典型真题完整解答

题 ★★★★★ 23-24-2 第 16 题（家庭电脑 400 户）：某品牌家用电脑年故障率 0.1，400 户独立使用。
  1. 用 Chebyshev 估计"故障数在 30-50 之间"的概率下界。
  2. 用 CLT 估计同一概率。
解

$S\sim B(400, 0.1)$。$E(S) = np = 40$，$D(S) = np(1-p) = 36$，$\sigma_S = 6$。事件 $\{30\leq S\leq 50\}$ 即 $\{|S-40|\leq 10\}$。

(1) Chebyshev：$P(|S-40|\leq 10) = P(|S-40|<10.001)\geq 1-\dfrac{36}{100} = 0.64$。

下界 0.64（粗糙）。

(2) CLT：$Z = \dfrac{S-40}{6}\approx N(0, 1)$。

$$P(|S-40|\leq 10) = P(|Z|\leq 10/6) = 2\Phi(1.667)-1\approx 2\cdot 0.952-1 = 0.904$$

对比：Chebyshev 给 0.64 下界，CLT 给约 0.90。CLT 更准确。

题 ★★★ 22-23-2 第 16 题（血型 1000 人）：某地 A 血型概率 0.2。1000 人调查，求 A 血型人数在 180-220 之间的概率。
解

$S\sim B(1000, 0.2)$。$E(S) = 200$，$D(S) = 160$，$\sigma_S = 12.65$。

$$P(180\leq S\leq 220)\approx P\!\left(\dfrac{180-200}{12.65}\leq Z\leq\dfrac{220-200}{12.65}\right) = \Phi(1.58)-\Phi(-1.58) = 2\Phi(1.58)-1\approx 0.886$$
题 ★★★（保险公司盈利）：保险公司接受 10000 单，每单年保费 12 元，赔付概率 0.006，赔付额 1000 元。求公司盈利不少于 60000 元的概率。
解

设 $X_i$ 为单 $i$ 赔付额（0 或 1000）。$E(X_i) = 6$，$D(X_i) = 1000^2\cdot 0.006-36 = 5964$。

总收入 $= 120000$。盈利 $\geq 60000$ ⇔ $\sum X_i\leq 60000$。

$\sum X_i\overset{近似}{\sim}N(60000, 10000\cdot 5964)$，$\sigma = \sqrt{5.964\times 10^7}\approx 7723$。

$$P(\sum X_i\leq 60000) = P(Z\leq 0) = 0.5$$

恰好 50%（因为均值线就是 60000）。

题 ★★★（反查 $n$）：每次测量误差 $\sim U(-1, 1)$ 独立。希望 $n$ 次平均误差落入 $[-0.1, 0.1]$ 的概率 $\geq 0.95$，求最少 $n$。
解

$E = 0$，$D = 1/3$，$\sigma = 1/\sqrt 3$。$\bar X\approx N(0, 1/(3n))$。

$$P(|\bar X|<0.1)\approx 2\Phi(0.1\sqrt{3n})-1\geq 0.95\Rightarrow\Phi(0.1\sqrt{3n})\geq 0.975$$

$0.1\sqrt{3n}\geq 1.96\Rightarrow n\geq\dfrac{1.96^2}{0.01\cdot 3}\approx 128.05$，取 $n = 129$。

六、易错点清单

  • 标准化分母用 $\sqrt n\sigma$（不是 $n\sigma$，也不是 $\sqrt n\sigma^2$）
  • $\bar X$ 的方差是 $\sigma^2/n$（除以 $n$ 不是 $\sqrt n$）
  • $\Phi(-x) = 1-\Phi(x)$：负参数查表时忘减号
  • 单位换算：例如"8 小时 = 480 分钟"
  • CLT 用于"和"或"均值"，单个变量不能用
  • $n$ 不够大时近似误差大
  • 注意区分 $\sum X_i$ 与 $\bar X$：两者均值方差不同
  • 二项分布近似正态时有连续性校正 $\pm 0.5$（教材未强调，但部分题目会用）
记忆口诀：
  • "i.i.d. 之和 ≈ $N(n\mu, n\sigma^2)$"（不要忘 $n$）
  • "$\bar X$ ≈ $N(\mu, \sigma^2/n)$"（方差除 $n$）
  • "标准化分母 $\sqrt n\sigma$"
  • "二项 $n$ 大 $p$ 适中 → 正态；$p$ 小 → Poisson"

七、扩展：CLT 的几种推广

满分笔记中提到的扩展定理（证明题潜在考点）：

  • Lindeberg-Feller：处理独立不同分布的情形，要求 Lindeberg 条件成立
  • Lyapunov：用 $E|X_i-\mu_i|^{2+\delta}$ 控制，证明 CLT
  • 三大 CLT 之间：Lindeberg-Lévy 是 i.i.d. 特例；Lindeberg-Feller 处理一般独立情形（最普适）；Lyapunov 条件是 Lindeberg 条件的充分条件（更易验证）

本课重点是 Lindeberg-Lévy（i.i.d.）和 De Moivre-Laplace（二项）。

八、真题套路 · 二级结论 · 速算技巧

CLT 题型决策树

题型套路

必背二级结论

  1. i.i.d. 之和近似正态：$\sum X_i\overset{近似}{\sim}N(n\mu, n\sigma^2)$
  2. 样本均值近似正态：$\bar X\overset{近似}{\sim}N(\mu, \sigma^2/n)$
  3. De Moivre-Laplace：$B(n,p)\Rightarrow$ 标准化后 $\to N(0,1)$
  4. $n$ 充分大 $\chi^2$ 渐近正态：$\chi^2(n)\approx N(n, 2n)$
  5. $n$ 大 $p$ 适中（$0.1
  6. $n$ 大 $p$ 小（$np\leq 10$）→ 二项近似 Poisson $P(np)$
  7. 误差累积公式：$n$ 个独立测量误差 $X_i\sim N(0, \sigma^2)$，$\bar X\sim N(0, \sigma^2/n)$
  8. 常用 $\Phi$ 值：$\Phi(1)=0.8413, \Phi(1.645)=0.95, \Phi(1.96)=0.975, \Phi(2.33)=0.99$
  9. 3$\sigma$ 原则：$P(|X-\mu|<3\sigma) = 0.9974$

速算与解题技巧

  1. 识别"独立同分布求和/均值"立刻想 CLT
  2. 标准化公式必背：$Z = \dfrac{S-n\mu}{\sqrt n\sigma}$（分母 $\sqrt n\sigma$！）
  3. 反查 $n$ 技巧：若要 $P\geq c$，解 $\Phi^{-1}(c) = z^*$，再代回方程
  4. 对称性：$P(|Z|\leq z) = 2\Phi(z)-1$
  5. 分位数倒查：$P(Z>1.96) = 0.025$；$P(|Z|>1.96) = 0.05$
  6. Chebyshev 给下界，CLT 给精确值，对比时先 Chebyshev 后 CLT

常错"小坑"清单

  • 标准化分母 $\sqrt n\sigma$（不是 $n\sigma$、$\sqrt n\sigma^2$、$n\sigma^2$）
  • $\bar X$ 的方差是 $\sigma^2/n$（除以 $n$，不是 $\sqrt n$）
  • $\Phi(-x) = 1-\Phi(x)$：负参数易忘
  • 单位换算：例如"8 小时 = 480 分钟"
  • CLT 用于"和"或"均值"，单个变量不能用
  • $n$ 不够大时近似误差：$n<30$ 时要谨慎
  • $\sum X_i$ 与 $\bar X$ 区分：均值方差不同
