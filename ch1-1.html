1.1 随机事件及其运算 ⭐

本节真题考频：14 套真题命中 8 套，多以选择题 1-2 题出现。
典型出题：用 $A,B,C$ 表示复合事件（"恰一个发生"等）· 化简事件 · 判断包含 / 互斥关系 · De Morgan 应用。

一、基本概念

随机试验 $E$ 的三条件
  1. 可在相同条件下重复进行；
  2. 所有可能结果事先已知且不止一个；
  3. 每次试验前无法预知哪个结果。
样本空间 / 样本点 / 事件
  • 样本空间 $\Omega$ = $E$ 所有可能结果的集合 $= \{\omega\}$
  • 样本点 $\omega$ = $E$ 的直接结果（基本事件）
  • 随机事件 $A, B, \ldots$ = $\Omega$ 的子集
  • 必然事件 $\Omega$；不可能事件 $\varnothing$
典型样本空间
  • 掷一颗骰子：$\Omega = \{1, 2, 3, 4, 5, 6\}$
  • 射击命中环数：$\Omega = \{0, 1, \ldots, 10\}$
  • 测量误差：$\Omega = \mathbb R$
  • 电话呼叫次数：$\Omega = \{0, 1, 2, \ldots\}$
  • 等公交时间：$\Omega = [0, +\infty)$

二、事件的七种关系运算（必背）

名称记号含义
包含$A\subset B$$A$ 发生必导致 $B$ 发生
相等$A = B$$A\subset B$ 且 $B\subset A$
和（并）$A\cup B$至少一个发生
积（交）$AB = A\cap B$同时发生
差$A-B = A\bar B$$A$ 发生 $B$ 不发生
互斥$AB = \varnothing$不能同时发生
对立$\bar A$（$A\bar A=\varnothing,A\cup\bar A=\Omega$）恰有一个发生
对立 vs 互斥：对立必互斥（$A\bar A=\varnothing$），但互斥未必对立（缺 $A\cup B=\Omega$ 条件）。

三、运算律（必背！）

  • 交换律：$A\cup B = B\cup A$；$AB = BA$
  • 结合律：$(A\cup B)\cup C = A\cup(B\cup C)$
  • 分配律：$(A\cup B)\cap C = (AC)\cup(BC)$
  • 重余律：$\overline{\bar A} = A$
  • 幂等律：$A\cup A = A$；$AA = A$
  • 吸收律：$A\cup\Omega = \Omega$；$A\cap\Omega = A$；$A\cup\varnothing = A$；$A\cap\varnothing = \varnothing$
  • 差化积：$A-B = A\bar B = A-AB$
⭐ De Morgan 对偶律（最重要！）
$$\overline{A\cup B} = \bar A\cap\bar B,\quad\overline{A\cap B} = \bar A\cup\bar B$$ $$\overline{\bigcup_{i=1}^n A_i} = \bigcap_{i=1}^n\bar A_i,\quad\overline{\bigcap_{i=1}^n A_i} = \bigcup_{i=1}^n\bar A_i$$

可推广到可列。"对一组事件求否定 → 翻每项 + 反转交并"

满分笔记技巧：化简顺序：先对立 → 再互交 → 最后并/差。即先用 De Morgan 把所有补号往里推，再合并交集，最后处理并和差。

四、典型题型

题型 1：用 $A, B, C$ 表示复合事件（每年选择题）

必背模板：
  • $A$ 发生而 $B, C$ 都不发生：$A\bar B\bar C$
  • $A, B, C$ 都不发生：$\bar A\bar B\bar C = \overline{A\cup B\cup C}$
  • $A, B, C$ 不都发生：$\overline{ABC} = \bar A\cup\bar B\cup\bar C$
  • 恰有一个发生：$A\bar B\bar C\cup\bar AB\bar C\cup\bar A\bar BC$
  • 恰有两个发生：$AB\bar C\cup A\bar BC\cup\bar ABC$
  • 至少一个发生：$A\cup B\cup C$
  • 至少两个发生：$AB\cup AC\cup BC$
  • 至多一个发生：$\overline{AB\cup AC\cup BC}$ = "至少两个发生的对立"
极易混淆：
  • "不都发生" = "至少一个不发生" = $\overline{ABC}$
  • "都不发生" = $\bar A\bar B\bar C = \overline{A\cup B\cup C}$
两者完全不同！前者只需漏一个就算；后者必须三个都没发生。每年选择题必出。

题型 2：化简事件

例：化简 $\overline{\bar A\bar B}\cup CAB$。
解

$\overline{\bar A\bar B} = A\cup B$（De Morgan）。$ABC\subset A\subset A\cup B$，故

$$\overline{\bar A\bar B}\cup ABC = (A\cup B)\cup ABC = A\cup B$$

结论：吸收掉 $ABC$，结果 $= A\cup B$。

五、易错点清单

  • "不都发生" ≠ "都不发生"
  • 差事件 $A-B$ 不要求 $B\subset A$
  • "互斥" ≠ "对立"（对立有额外条件 $A\cup B = \Omega$）
  • De Morgan 应用时漏补号
  • 用文氏图辅助理解（推荐画三圆交叠）
记忆口诀：
  • "否定一组事件 = 翻成对立 + 反转并交"
  • "恰 $k$ 个发生：先选 $k$ 个发生，剩下取补，再并"
  • "至少 $k$ 个 → 对立至多 $k-1$ 个"

六、真题套路 · 二级结论 · 速算技巧

"恰 $k$ 个发生"通用模板

⭐ 三事件 $A, B, C$
题型表达式
都发生$ABC$
都不发生$\bar A\bar B\bar C = \overline{A\cup B\cup C}$
不都发生$\overline{ABC} = \bar A\cup\bar B\cup\bar C$
恰一个发生$A\bar B\bar C\cup\bar AB\bar C\cup\bar A\bar BC$
恰两个发生$AB\bar C\cup A\bar BC\cup\bar ABC$
至少一个$A\cup B\cup C$
至少两个$AB\cup AC\cup BC$
至多两个$\overline{ABC}$ = "至少一个不发生"

必背二级结论

  1. De Morgan：$\overline{A\cup B} = \bar A\bar B$；$\overline{AB} = \bar A\cup\bar B$
  2. 差化积：$A-B = A\bar B = A-AB$
  3. 包含传递：$A\subset B\Rightarrow\bar B\subset\bar A$
  4. 对立 vs 互斥：对立必互斥，反之未必
  5. 互斥的补不一定互斥：$AB = \varnothing$ 不蕴含 $\bar A\bar B = \varnothing$
  6. "恰 $k$ 个发生"的对称性：在 $n$ 事件中"恰 $k$ 个"和"恰 $n-k$ 个"的事件个数相同

速算与解题技巧

  1. 化简优先用 De Morgan："先对立 → 再互交 → 最后并/差"
  2. "不都" vs "都不"区分：写英文 not-all vs all-not
  3. "至少 $k$" 用对立 "至多 $k-1$"，往往更简洁
  4. 画文氏图辅助：复杂事件用三圆交叠图理解
  5. 事件互不相同时：$A_iA_j$ 形如交集要逐一展开

常错"小坑"清单

  • "不都发生" ≠ "都不发生"（每年选择题至少 1 题考此区分）
  • 差事件 $A-B$ 不要求 $B\subset A$
  • "互斥" ≠ "对立"
  • De Morgan 应用时漏补号
  • "恰 $k$ 个"忘了枚举所有组合（$n=3, k=1$ 时有 3 种）

🔥 章节强化：真题原型 + 必背 + 易错

📜 历年真题原型（事件表示 / 命题判断）

真题原型 1（23-24-2 题12 · 4 命题判正确个数）：判断下列命题正确的个数。
  1. $P(AB\mid A)\ge P(AB\mid A\cup B)$
  2. $P(A\mid B)=1\Rightarrow P(\bar B\mid\bar A)=1$
  3. $A\bar B=\bar AB\Rightarrow A=B$
  4. "$A,B$ 恰有一个发生"的概率 $=P(A)+P(B)-2P(AB)$
解

① $A\subset A\cup B$，分母变大则条件概率变小，故 $P(AB\mid A)\ge P(AB\mid A\cup B)$，✓。

② $P(A\mid B)=1\Rightarrow B\subset A\Rightarrow\bar A\subset\bar B\Rightarrow P(\bar B\mid\bar A)=1$，✓。

③ 由 $A\bar B=\bar AB$，两边求并 $A=A(B\cup\bar B)=AB\cup A\bar B=AB\cup\bar AB=(A\cup\bar A)B=B$，✓。

④ 恰一个发生 $=A\bar B\cup\bar AB$，两项互斥，概率 $=P(A)-P(AB)+P(B)-P(AB)=P(A)+P(B)-2P(AB)$，✓。

结论：4 个全对，选 D。

真题原型 2（事件表示 · 每年选择题套路）：设 $A,B,C$ 为三事件，用运算表示"$A,B,C$ 中恰有一个发生"及"至少两个发生"。
解

恰有一个发生：$A\bar B\bar C\cup\bar AB\bar C\cup\bar A\bar BC$（先选谁发生，其余取补，三项互斥求并）。

至少两个发生：$AB\cup AC\cup BC$（两两交的并，已自动含三个全发生的情形）。

其概率：恰一个 $=P(A)+P(B)+P(C)-2[P(AB)+P(AC)+P(BC)]+3P(ABC)$。

⭐ 必背块

核心运算律 / 判据
  • De Morgan：$\overline{A\cup B}=\bar A\bar B$，$\overline{AB}=\bar A\cup\bar B$（可推广到可列）。
  • 差化积：$A-B=A\bar B=A-AB$；差事件不要求 $B\subset A$。
  • 包含取补反向：$A\subset B\Rightarrow\bar B\subset\bar A$。
  • 对立 vs 互斥：对立必互斥（$A\bar A=\varnothing$），互斥未必对立（缺 $A\cup B=\Omega$）。
  • 恰一个对称性：$n$ 事件中"恰 $k$ 个发生"与"恰 $n-k$ 个发生"的项数相同。
三事件"恰 $k$ 个"模板（背死）
  • 都发生 $ABC$；都不发生 $\bar A\bar B\bar C=\overline{A\cup B\cup C}$；不都发生 $\overline{ABC}=\bar A\cup\bar B\cup\bar C$。
  • 恰一个 $A\bar B\bar C\cup\bar AB\bar C\cup\bar A\bar BC$；恰两个 $AB\bar C\cup A\bar BC\cup\bar ABC$。
  • 至少一个 $A\cup B\cup C$；至少两个 $AB\cup AC\cup BC$。

⚠️ 易错点

  • "不都发生" ≠ "都不发生"：前者 $=\overline{ABC}$（漏一个就算），后者 $=\overline{A\cup B\cup C}$（必须三个都不发生）。每年选择题必考。
  • De Morgan 漏补号：翻交并时必须把每一项也取补，$\overline{A\cup B}=\bar A\bar B$ 不是 $\bar A\cup\bar B$。
  • 互斥 ≠ 对立 ≠ 不独立：互斥是集合关系 $AB=\varnothing$；独立是概率关系 $P(AB)=P(A)P(B)$；概率非零的互斥事件一定不独立，别混。
