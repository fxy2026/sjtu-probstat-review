1.3 条件概率 · 全概率 · Bayes 公式 ⭐⭐⭐

本节真题考频：14 套真题命中 13 套（93%）。全概率公式 12 次、Bayes 公式 13 次。
必出位置：每年大题第 13 题（9 分），命中率 100%。多年雷打不动。
近 5 年题型：23-24-2 三门高射炮 / 23-24-1 次品检验 / 22-23-2 三类驾驶员 / 20-21-2 三类投保人 / 19-20-1 射手三级。

一、条件概率定义与本质

定义

设 $P(B) > 0$，事件 $B$ 已发生条件下 $A$ 发生的概率：

$$P(A\mid B) = \dfrac{P(AB)}{P(B)}$$
本质：条件概率把样本空间 $\Omega$ 缩小为 $B$（"重新归一化"）；$A$ 在新空间中的占比即 $P(A\mid B)$。
条件概率也满足三公理

$P(\cdot\mid B)$ 本身是一个概率测度，所以下列性质在条件下也成立：

  • $P(\bar A\mid B) = 1 - P(A\mid B)$
  • $P(A\cup C\mid B) = P(A\mid B) + P(C\mid B) - P(AC\mid B)$
  • 条件下的容斥公式

用途：题目给出"在 $B$ 条件下" 的概率时，可以放心用上面这些性质处理。

二、乘法公式（两事件 + n 事件）

⭐ 乘法公式
$$P(AB) = P(B)P(A\mid B) = P(A)P(B\mid A)$$

推广到 $n$ 事件（$P(A_1A_2\cdots A_{n-1}) > 0$）：

$$P(A_1A_2\cdots A_n) = P(A_1)\,P(A_2\mid A_1)\,P(A_3\mid A_1A_2)\cdots P(A_n\mid A_1\cdots A_{n-1})$$
例 1（抽签的公平性，多年真题原型）：袋中 $a$ 难签 + $b$ 易签。$n$ 人依次不放回抽。求第 $k$ 人抽到难签的概率。
解（两种方法）

法 1（古典概型）：考虑所有 $a+b$ 个签的全排列，每个等可能。第 $k$ 位上是难签的方案数 = $a\cdot (a+b-1)!$。所以 $P = \dfrac{a\cdot (a+b-1)!}{(a+b)!} = \dfrac{a}{a+b}$。

法 2（递推）：记 $A_k$="第 $k$ 人抽难签"。$P(A_1) = \dfrac{a}{a+b}$。

$$P(A_2) = P(A_1)P(A_2\mid A_1) + P(\bar A_1)P(A_2\mid\bar A_1) = \dfrac{a}{a+b}\cdot\dfrac{a-1}{a+b-1}+\dfrac{b}{a+b}\cdot\dfrac{a}{a+b-1} = \dfrac{a}{a+b}$$

归纳：$P(A_k) = \dfrac{a}{a+b}$，与 $k$ 无关。"先抽后抽都公平"。

三、全概率公式 ⭐⭐⭐

⭐ 全概率公式

设 $\{B_1, B_2, \ldots, B_n\}$ 是 $\Omega$ 的一个划分（两两互斥，且 $\bigcup_i B_i = \Omega$，$P(B_i) > 0$），则对任意事件 $A$：

$$P(A) = \sum_{i=1}^n P(B_i)P(A\mid B_i)$$
三步使用法：
  1. 验证 $\{B_i\}$ 是划分：两两互斥 + 并为 $\Omega$（缺一不可）
  2. 列已知：$P(B_i)$（先验）和 $P(A\mid B_i)$（条件）
  3. 套公式：加权求和
例 2（保险公司，PPT 经典）：投保人分三类（按危险概率比 $2:5:3$）："安全型"占 20%、"一般型"占 50%、"危险型"占 30%。年出险概率分别 $0.05, 0.15, 0.30$。
  1. 任一投保人年内出险的概率？
  2. 已知出险，求是"危险型"的概率？
解

记 $A$ = "出险"，$B_1, B_2, B_3$ 为三类。验证：两两互斥（每人属一类）+ 并为全体（覆盖）。

(1) 全概率：$P(A) = 0.2\cdot 0.05 + 0.5\cdot 0.15 + 0.3\cdot 0.30 = 0.01 + 0.075 + 0.09 = 0.175$

(2) Bayes：$P(B_3\mid A) = \dfrac{0.3\cdot 0.30}{0.175} = \dfrac{0.09}{0.175}\approx 0.514$

先验 0.3 → 后验 0.514，反映"看到出险这条证据后，怀疑此人是危险型的程度增加"。

例 3（多源产品检验）：工厂三车间生产同种产品，产量比 $4:3:3$，次品率分别 $2\%, 3\%, 5\%$。任取一件检验。
  1. 取到次品的概率。
  2. 已知次品，求来自第一车间的概率。
解

设 $B_i$ = 来自车间 $i$（$i=1,2,3$），$A$ = 次品。$P(B_1)=0.4, P(B_2)=P(B_3)=0.3$。

(1) $P(A) = 0.4\cdot 0.02 + 0.3\cdot 0.03 + 0.3\cdot 0.05 = 0.008 + 0.009 + 0.015 = 0.032$

(2) $P(B_1\mid A) = \dfrac{0.4\cdot 0.02}{0.032} = \dfrac{0.008}{0.032} = 0.25$

先验 $P(B_1) = 0.4$ → 后验 0.25，"次品更可能来自后两个车间"。

四、Bayes 公式 ⭐⭐⭐

⭐ Bayes 公式（贝叶斯定理）

同上设定，$P(A) > 0$，则

$$P(B_i\mid A) = \dfrac{P(B_i)P(A\mid B_i)}{\sum_{j=1}^n P(B_j)P(A\mid B_j)} = \dfrac{P(B_i)P(A\mid B_i)}{P(A)}$$

分子：单一路径 "$B_i \to A$" 的贡献。

分母：所有路径总贡献 = 全概率公式。

必踩坑：Bayes 分母必须展开成全概率形式。直接写 $P(A)$ 是过程不全（虽然结果对），多个真题答案要求展开计算。
题 ★★★★★ 23-24-2 第 13 题（三门高射炮，命中率最高的 Bayes 题）：甲乙丙三门炮独立射击，命中率 $p_1=0.4, p_2=0.5, p_3=0.7$。摧毁规则：仅一门击中 → 摧毁概率 0.2；两门击中 0.6；三门全中 1。
  1. 求目标被摧毁的概率。
  2. 已知目标被摧毁，求恰两门击中的概率。
解（满分模板）

Step 1： 设 $B_k$ = "恰 $k$ 门击中"，$A$ = "被摧毁"。$\{B_0, B_1, B_2, B_3\}$ 是划分。

Step 2： 算 $P(B_k)$（关键：每一项是 3 种组合相加！）

  • $P(B_0) = 0.6\cdot 0.5\cdot 0.3 = 0.09$
  • $P(B_1) = 0.4\cdot 0.5\cdot 0.3 + 0.6\cdot 0.5\cdot 0.3 + 0.6\cdot 0.5\cdot 0.7 = 0.06 + 0.09 + 0.21 = 0.36$
  • $P(B_2) = 0.4\cdot 0.5\cdot 0.3 + 0.4\cdot 0.5\cdot 0.7 + 0.6\cdot 0.5\cdot 0.7 = 0.06 + 0.14 + 0.21 = 0.41$
  • $P(B_3) = 0.4\cdot 0.5\cdot 0.7 = 0.14$

验算 $\sum P(B_k) = 0.09 + 0.36 + 0.41 + 0.14 = 1$ ✓

Step 3： 全概率算 $P(A)$：

$$P(A) = 0\cdot 0.09 + 0.2\cdot 0.36 + 0.6\cdot 0.41 + 1\cdot 0.14 = 0 + 0.072 + 0.246 + 0.14 = 0.458$$

Step 4： Bayes 反推：

$$P(B_2\mid A) = \dfrac{P(B_2)P(A\mid B_2)}{P(A)} = \dfrac{0.41\cdot 0.6}{0.458}\approx 0.537$$

易错点：(1) $P(B_1)$ 和 $P(B_2)$ 都要枚举 3 种"哪门击中、哪两门未击中"的组合，不能漏；(2) Bayes 分母用 step 3 的结果 0.458，不要重算。

题 ★★★★★ 23-24-1 第 13 题（次品检验，标准 Bayes）：工厂三车间生产同种产品，产量比 $4:3:3$，次品率分别 $2\%, 3\%, 5\%$。
  1. 任取一件，求是次品的概率。
  2. 已知是次品，求来自第 1 车间的概率。
解

设 $B_i$ = 来自车间 $i$，$A$ = 次品。$P(B_1) = 0.4, P(B_2) = P(B_3) = 0.3$。

(1) $P(A) = 0.4\cdot 0.02 + 0.3\cdot 0.03 + 0.3\cdot 0.05 = 0.008 + 0.009 + 0.015 = 0.032$

(2) $P(B_1\mid A) = \dfrac{0.008}{0.032} = 0.25$

先验 $P(B_1) = 0.4$ → 后验 0.25，说明"次品更可能来自后两个车间"。

例（医学诊断反直觉）：某病发病率 0.005，化验对患者阳性率 0.95，对健康人误诊率 0.04。求一阳性者真患病的概率。
解
$$P(D\mid T^+) = \dfrac{0.005\cdot 0.95}{0.005\cdot 0.95 + 0.995\cdot 0.04} = \dfrac{0.00475}{0.04455}\approx 0.107$$

测试看似很准（敏感性 95%，特异性 96%），但由于发病率低，阳性者真患病概率只有 10.7%。这是 Bayes 思维的经典演示——基率不能忽视。

五、解题标准模板（必背！）

⭐ 真题题 13 满分答题五步法
  1. 设事件：用 $A,B_i$ 明确标记"目标事件"和"原因划分"，定义清晰
  2. 验证划分：写一行 "$\{B_i\}$ 两两互斥且 $\bigcup B_i = \Omega$"
  3. 列已知概率：$P(B_i)$（先验）和所有 $P(A\mid B_i)$（条件）
  4. 算 $P(A)$：套全概率公式，每项展开写（不要直接算最终数字）
  5. 反推 $P(B_k\mid A)$：分子单条路径，分母用 step 4 的结果
近 5 年真题"剧情"清单（题 13 反复用的几种背景）：
  • 多源产品检验（3 个工厂 / 3 类原料）
  • 信道传输错误（0/1 信号传输）
  • 射击命中（多门炮 / 多个射手）
  • 医学诊断（疾病 vs 健康，敏感性 vs 特异性）
  • 多类抽样（保险三类 / 驾驶员三级）

不管剧情怎么变，解法完全一样——按五步走。

六、易错点清单

本节超纲常错（每年都有人栽）：
  • 没验证 $\{B_i\}$ 是划分：更糟的是用了不互斥的"原因"（如 $B_1$="开火"，$B_2$="有目标"——这两个不互斥）
  • $P(B_i)$ 没穷尽：例如"恰一门击中"忘了 3 种组合相加
  • Bayes 分母直接写 $P(A)$：扣过程分；要展开成全概率形式
  • $P(A\mid B)$ 与 $P(B\mid A)$ 弄反：典型"基率谬误"，医学题最常见
  • 条件下又用乘法公式时：每一步都要加 $|B$，不要丢条件
  • 验证不归一：算完 $P(B_k)$ 后忘了用 $\sum P(B_k) = 1$ 检查
记忆口诀：
  • "先全概，后 Bayes，分母就是全概率"
  • "分类讨论 → 加权平均 → 反推路径"
  • 看到"已知 / 在...条件下，求..."就上 Bayes

七、本节满分级补充（来自学姐 44 页笔记）

条件概率的三大公式总览（笔记原话）：

  1. 乘法公式：$P(AB) = P(B)P(A\mid B)$ 与 $P(A_1\cdots A_n) = P(A_1)P(A_2\mid A_1)\cdots P(A_n\mid A_1\cdots A_{n-1})$
  2. 全概率公式：用于"已知各种路径，求总概率"
  3. Bayes 公式：用于"已知结果，反推路径"
典型几何概型 + 条件概率联考：

$(X,Y)$ 在单位正方形 $[0,1]^2$ 均匀分布。求 $P(X<1/2\mid X+Y<1)$。

$P(X+Y<1)=1/2$（下三角形面积）；$P(X<1/2, X+Y<1)$ = 在三角形内截取 $x<1/2$ 的区域面积。

条件概率 = 分子面积 / 分母面积，最终 $= 3/4$。

八、真题套路 · 二级结论 · 速算技巧

套路一览（按真题剧情）

⭐ 5 种剧情 → 同一套路
剧情$B_i$ 划分$P(A\mid B_i)$ 类型
三类产品 / 多源工厂来自工厂 $i$（占比 $\alpha_i$）次品率 $p_i$
三类人 / 多类投保身份类别（占比 $\alpha_i$）事件率 $p_i$（出险/事故）
多门炮 / 多个射手"恰 $k$ 门击中"（枚举组合相加）条件下摧毁率
信道传输原始信号 0/1（先验 $p_0, p_1$）转移概率
医学诊断患病 / 健康敏感性 / 1 - 特异性

必背二级结论

  1. 抽签公平性：$n$ 人不放回抽 $a$ 难签 + $b$ 易签，每人抽到难签的概率都是 $a/(a+b)$，与位置无关
  2. "恰 $k$ 门击中"组合数（独立异概率）：$P(B_k) = \sum_{|S|=k}\prod_{i\in S}p_i\prod_{j\notin S}(1-p_j)$
  3. "条件概率也是概率"：$P(\cdot\mid B)$ 满足三公理，可用容斥、对立
  4. Bayes 几何意义：分子是"路径权重"，分母是"全路径总和"
  5. 独立 → $P(A\mid B) = P(A)$（条件不改变概率）
  6. Bayes 在医学诊断中的反直觉：发病率低时，即便测试很准，阳性者真患病概率也很低（基率谬误）

速算与解题技巧

  1. 验证 $\sum P(B_k) = 1$ —— 算完所有 $P(B_k)$ 后立刻验证，发现错算可挽回
  2. Bayes 分子分母同时算：分母 = 第一问的 $P(A)$，不重算
  3. "枚举 $k$ 门击中"的组合数：$n$ 门时 $C_n^k$ 种，每种独立计算后相加
  4. 条件概率题反向变换：$P(A\mid B) = \dfrac{P(B\mid A)P(A)}{P(B)}$，看哪边好算选哪边
  5. 多重条件 $P(A\mid B, C)$：先固定 $B, C$ 把样本空间缩到 $BC$，再算 $A$

常错"小坑"清单

  • 没算 $P(B_0)$（"全不发生"）—— 虽然往往用不到，但验证 $\sum=1$ 必须包含
  • $P(B_1)$ "恰一门击中" 忘了枚举 3 种组合相加
  • Bayes 分母直接写 $P(A)$ 不展开 —— 扣过程分
  • 把 $P(B\mid A)$ 与 $P(A\mid B)$ 弄反 —— 医学题典型陷阱
  • "条件 + 容斥" 时忘了加 $\mid B$（每一步都要带条件）
