4.4 高阶矩与协方差矩阵 ⭐

本节真题考频：14 套真题命中 4 套，多为选择/填空。
典型出题：协方差矩阵性质（对称、半正定）· $n$ 维正态独立 ⇔ 对角阵 · $D(\sum t_iX_i) = \mathbf t^T\mathbb C\mathbf t$。

一、各种"矩"

  • $k$ 阶原点矩：$\mu_k = E(X^k)$
  • $k$ 阶中心矩：$\nu_k = E[(X-EX)^k]$
  • $\mu_1 = E(X)$；$\nu_2 = D(X)$
  • 混合矩：$E(X^k Y^l)$
  • 混合中心矩：$E[(X-EX)^k(Y-EY)^l]$；$(1, 1)$ 阶是 $\Cov(X, Y)$
原点矩包含位置信息；中心矩消除位置只留分布形状。3 阶中心矩反映偏度，4 阶反映峰度。

二、协方差矩阵

$n$ 维随机变量 $(X_1, \ldots, X_n)$ 的协方差矩阵

$$\mathbb C = \begin{pmatrix}c_{11}&c_{12}&\cdots&c_{1n}\\c_{21}&c_{22}&\cdots&c_{2n}\\\vdots&\vdots&\ddots&\vdots\\c_{n1}&c_{n2}&\cdots&c_{nn}\end{pmatrix},\quad c_{ij} = \Cov(X_i, X_j)$$

性质：对称、半正定。对角元 $c_{ii} = D(X_i)$。

线性组合方差
$$D\!\left(\sum_{i=1}^n t_i X_i\right) = \sum_{i,j}t_i t_j c_{ij} = \mathbf t^T\mathbb C\mathbf t$$

这是协方差矩阵的"几何意义"——线性组合的方差由二次型给出。

例：二维正态 $(X, Y)\sim N(\mu_1, \mu_2, \sigma_1^2, \sigma_2^2, \rho)$ 的协方差矩阵： $$\mathbb C = \begin{pmatrix}\sigma_1^2&\rho\sigma_1\sigma_2\\\rho\sigma_1\sigma_2&\sigma_2^2\end{pmatrix},\quad|\mathbb C| = \sigma_1^2\sigma_2^2(1-\rho^2)$$ $\rho = \pm 1$ 时 $|\mathbb C| = 0$，矩阵退化。

三、$n$ 维正态分布

$n$ 维正态随机向量 $\mathbf X = (X_1, \ldots, X_n)^T\sim N(\boldsymbol\mu, \mathbb C)$ 密度：

$$f(\mathbf x) = \dfrac{1}{(2\pi)^{n/2}|\mathbb C|^{1/2}}\exp\!\left[-\dfrac{1}{2}(\mathbf x-\boldsymbol\mu)^T\mathbb C^{-1}(\mathbf x-\boldsymbol\mu)\right]$$

$\mathbb C$ 正定，$\boldsymbol\mu$ 是均值向量。

⭐ $n$ 维正态四大性质
  1. 任意子集仍是低维正态
  2. 任意线性组合 $\sum a_iX_i$ 服从一维正态
  3. $X_i$ 相互独立 ⇔ 协方差矩阵 $\mathbb C$ 是对角矩阵（仅在正态下成立！）
  4. 线性变换仍正态：$\mathbf Y = A\mathbf X+\mathbf b\sim N(A\boldsymbol\mu+\mathbf b, A\mathbb C A^T)$

四、考试要点

本节常出选择/填空 1-2 题。重点：协方差矩阵性质 + $n$ 维正态独立判别（对角阵）+ $D(\sum t_iX_i)$ 二次型计算。
易错：
  • "$\mathbb C$ 对角 ⇔ 独立" 仅对 $n$ 维正态成立，一般分布不成立
  • 协方差矩阵半正定（不一定正定，因为 $\rho = \pm 1$ 时退化）
  • $D(\sum t_iX_i)$ 的二次型展开要注意 $i\neq j$ 项有两次贡献
记忆口诀：
  • "协方差矩阵：对称 + 半正定"
  • "正态下 $\mathbb C$ 对角 = 独立；一般分布不行"
  • "$D(\mathbf t^T\mathbf X) = \mathbf t^T\mathbb C\mathbf t$"

五、真题套路 · 二级结论 · 速算技巧

必背二级结论

  1. 协方差矩阵性质：对称 + 半正定
  2. $D(\sum t_iX_i) = \mathbf t^T\mathbb C\mathbf t$（二次型）
  3. $n$ 维正态独立 ⇔ $\mathbb C$ 对角（仅在正态下！）
  4. 任意子集仍是低维正态（性质 1）
  5. 任意线性组合 $\sum a_iX_i$ 服从一维正态（性质 2）
  6. 线性变换：$\mathbf Y = A\mathbf X+\mathbf b\sim N(A\boldsymbol\mu+\mathbf b, A\mathbb C A^T)$
  7. $|\mathbb C|$ 是 $\sigma_1^2\sigma_2^2(1-\rho^2)$（二维正态）
  8. $\mathbb C$ 半正定，所以 $|\mathbb C|\geq 0$；$\rho = \pm 1$ 时退化

速算与解题技巧

  1. $n$ 维正态判独立 → 看 $\mathbb C$ 是否对角
  2. 线性组合的分布 → $a\mu+b$ 和 $a^T\mathbb C a$
  3. 二次型 $\mathbf t^T\mathbb C\mathbf t$ 展开：对角项 $t_i^2 c_{ii}$ + 交叉项 $2t_it_j c_{ij}$

常错"小坑"清单

  • "$\mathbb C$ 对角 ⇔ 独立" 仅对 $n$ 维正态，一般分布不行
  • $\mathbb C$ 半正定不是正定，$\rho=\pm 1$ 时退化
  • $D(\sum t_iX_i)$ 二次型：交叉项有 2 倍系数

六、历年真题原型

题 ★★★★ 22-23-2 第 10 题（经典陷阱：边缘正态 ⇏ 联合正态）：已知 $X\sim N(\mu,\sigma^2)$、$Y\sim N(\mu,\sigma^2)$，相关系数 $\rho_{X,Y} = -0.3$（只给边缘正态，没说联合正态！）。判断下列命题对错：① $(X,Y)$ 服从二维正态；② $\D(X-2Y) = 6.2\sigma^2$；③ $X+Y$ 与 $X-Y$ 不相关；④ $X+Y$ 与 $X-Y$ 相互独立。
解

① 错。边缘各自正态 不能推出联合二维正态（可构造反例）。

② 对。$\Cov(X,Y) = \rho\sigma^2 = -0.3\sigma^2$，故

$$\D(X-2Y) = \D(X)+4\D(Y)-2\cdot 2\Cov(X,Y) = \sigma^2+4\sigma^2-4(-0.3\sigma^2) = 6.2\sigma^2$$

③ 对。$\Cov(X+Y,X-Y) = \D(X)-\D(Y) = \sigma^2-\sigma^2 = 0$（只要边缘同方差即成立，不需正态）。

④ 错！独立需要联合正态，而①已说明联合不一定正态，故"不相关 $\nRightarrow$ 独立"。

正确答案 ②③（选 D）。教训：不相关 $\Rightarrow$ 独立这一步只在确认 $(X,Y)$ 联合正态时才成立；边缘各自正态不够。

题 ★★★★ 23-24-2 第 1 题（二维正态找不相关线性组合）：$(X,Y)\sim N(0,1;\,0,4;\,-0.5)$。找一个服从 $N(0,1)$ 且与 $X$ 不相关的线性组合。
解

这里 $\sigma_1 = 1,\sigma_2 = 2,\rho = -0.5$，故 $\Cov(X,Y) = \rho\sigma_1\sigma_2 = (-0.5)(1)(2) = -1$。

试 $X+Y$：$\Cov(X,X+Y) = \D(X)+\Cov(X,Y) = 1+(-1) = 0$，确实与 $X$ 不相关！

方差：$\D(X+Y) = \sigma_1^2+\sigma_2^2+2\Cov(X,Y) = 1+4+2(-1) = 3$。

标准化得 $\dfrac{1}{\sqrt 3}(X+Y)\sim N(0,1)$（线性组合在二维正态下仍正态，性质 2）。

另：第 7 问 $\bar X,\bar Y$ 的相关系数 $\rho_{\bar X,\bar Y} = \rho_{X,Y} = -0.5$（样本均值相关系数不变）。

七、必背块（协方差矩阵核心）

  • 协方差矩阵 $\mathbb C$：对称 + 半正定，对角元 $c_{ii} = \D(X_i)$。
  • 二维正态协方差矩阵 $\mathbb C = \begin{pmatrix}\sigma_1^2&\rho\sigma_1\sigma_2\\\rho\sigma_1\sigma_2&\sigma_2^2\end{pmatrix}$，$|\mathbb C| = \sigma_1^2\sigma_2^2(1-\rho^2)$。
  • $\Cov(X,Y) = \rho\sigma_1\sigma_2$（记成 $\rho\cdot$ 两个标准差之积）。
  • 线性组合方差（二次型）：$\D(\sum t_iX_i) = \mathbf t^T\mathbb C\mathbf t$。
  • $\D(aX+bY) = a^2\sigma_1^2+b^2\sigma_2^2+2ab\,\rho\sigma_1\sigma_2$（系数平方，交叉项带 $2ab$）。
  • $n$ 维正态：$X_i$ 相互独立 $\Leftrightarrow$ $\mathbb C$ 对角 $\Leftrightarrow$ 两两不相关（仅正态下！）。
  • 线性变换：$\mathbf Y = A\mathbf X+\mathbf b\sim N(A\boldsymbol\mu+\mathbf b,\,A\mathbb C A^T)$。
  • 不相关 4 等价：$\rho = 0\Leftrightarrow\Cov = 0\Leftrightarrow E(XY) = EX\cdot EY\Leftrightarrow\D(X+Y) = \D X+\D Y$。

八、易错点

  • "不相关 $\Rightarrow$ 独立" 只在确认联合正态时成立。边缘各自正态不够（22-23-2[10] 陷阱）。
  • $\D(X-Y) = \D X+\D Y-2\Cov(X,Y)$，减号项的符号别错；$\Cov$ 本身还可能是负的（如 $\rho<0$），双重负号要算清。
  • 协方差矩阵半正定而非正定，$\rho = \pm 1$ 时 $|\mathbb C| = 0$ 退化。
