7.2 区间估计 ⭐⭐

本节真题考频：14 套真题命中 10 套（71%）。常作为大题 19 备选题型。
典型出题：$\mu$ 的双侧/单侧置信区间 · $\sigma^2$ 的置信区间 · 选择置信度对应分位数。

一、置信区间的概念

对未知参数 $\theta$ 构造统计量 $\underline\theta, \bar\theta$（仅依赖样本），使

$$P(\underline\theta\leq\theta\leq\bar\theta)\geq 1-\alpha$$

$[\underline\theta, \bar\theta]$ 称为 $\theta$ 的置信水平 $1-\alpha$ 的置信区间。$\alpha$ 是显著性水平（一般 0.05 或 0.01）。

枢轴量法：找一个含 $\theta$ 且分布已知的统计量 $T = T(\bar X, S, \theta)$，反解出 $\theta$ 的区间。

二、单个正态总体（最重要！）

2.1 $\mu$ 的置信区间

情形 1：$\sigma^2$ 已知

枢轴量 $U = \dfrac{\bar X-\mu}{\sigma/\sqrt n}\sim N(0, 1)$：

$$\left[\bar X-u_{\alpha/2}\dfrac{\sigma}{\sqrt n},\;\bar X+u_{\alpha/2}\dfrac{\sigma}{\sqrt n}\right]$$

情形 2：$\sigma^2$ 未知（更常见）

枢轴量 $T = \dfrac{\bar X-\mu}{S/\sqrt n}\sim t(n-1)$：

$$\left[\bar X-t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n},\;\bar X+t_{\alpha/2}(n-1)\dfrac{S}{\sqrt n}\right]$$

2.2 $\sigma^2$ 的置信区间

$\mu$ 已知：枢轴量 $\chi^2 = \dfrac{1}{\sigma^2}\sum(X_i-\mu)^2\sim\chi^2(n)$：

$$\left[\dfrac{\sum(X_i-\mu)^2}{\chi^2_{\alpha/2}(n)},\;\dfrac{\sum(X_i-\mu)^2}{\chi^2_{1-\alpha/2}(n)}\right]$$

$\mu$ 未知（更常见）：$\chi^2 = \dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$：

$$\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\;\dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$$

注意 $\chi^2$ 不对称，上下分位数不同。

题 ★（标准 $t$ 区间）：$n = 16, \bar X = 2.125, S = 0.017, \alpha = 0.05$，正态总体方差未知。求 $\mu$ 的 95% 置信区间。
解

$t_{0.025}(15) = 2.131$。半宽 $= 2.131\cdot\dfrac{0.017}{\sqrt{16}} = 0.00906$。

区间 $[2.125-0.00906, 2.125+0.00906] = [2.116, 2.134]$。

三、两个正态总体

  • $\mu_1-\mu_2$（$\sigma_1^2, \sigma_2^2$ 已知）：枢轴量 $U\sim N(0,1)$，
$$\bar X-\bar Y\pm u_{\alpha/2}\sqrt{\dfrac{\sigma_1^2}{n_1}+\dfrac{\sigma_2^2}{n_2}}$$
  • $\mu_1-\mu_2$（$\sigma_1^2 = \sigma_2^2$ 未知）：用合并方差 $S_w^2 = \dfrac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$，
$$\bar X-\bar Y\pm t_{\alpha/2}(n_1+n_2-2)\cdot S_w\sqrt{\dfrac{1}{n_1}+\dfrac{1}{n_2}}$$
  • $\sigma_1^2/\sigma_2^2$：枢轴量 $F = \dfrac{S_1^2/\sigma_1^2}{S_2^2/\sigma_2^2}\sim F(n_1-1, n_2-1)$，
$$\dfrac{S_1^2/S_2^2}{F_{\alpha/2}(n_1-1, n_2-1)}\leq\dfrac{\sigma_1^2}{\sigma_2^2}\leq\dfrac{S_1^2/S_2^2}{F_{1-\alpha/2}(n_1-1, n_2-1)}$$

四、单侧置信区间

单侧上限：$P(\theta\leq\bar\theta)\geq 1-\alpha$，用分位数 $u_\alpha$（不是 $u_{\alpha/2}$！）。

例：$N(\mu, \sigma^2)$，$\sigma^2$ 未知，$\mu$ 的单侧上限

$$\bar\mu = \bar X+t_\alpha(n-1)\dfrac{S}{\sqrt n}$$

单侧置信区间 $(-\infty, \bar\mu)$。

单 vs 双：双侧用 $\alpha/2$ 分位数（两边各 $\alpha/2$），单侧用 $\alpha$ 分位数（只一边）。

五、易错点清单

  • $\chi^2$ 不对称，分位数上下分别用 $\chi^2_{\alpha/2}$ 和 $\chi^2_{1-\alpha/2}$（注意大数除以大、小数除以小，要看分位数大小对应方差大小）
  • 双侧用 $\alpha/2$，单侧用 $\alpha$
  • $\sigma$ 未知时必须用 $t$（不能用 $u$）
  • $F$ 区间利用倒数关系 $F_{1-\alpha/2}(m, n) = 1/F_{\alpha/2}(n, m)$ 查左尾
  • "置信区间"是随机区间（覆盖 $\theta$ 的概率 = $1-\alpha$），不是说 $\theta$ 在该区间的概率
记忆口诀：
  • "$\sigma$ 已知 → $u$；$\sigma$ 未知 → $t$"
  • "方差 $\sigma^2$ 估计 → $\chi^2$；方差比 → $F$"
  • "双 $\alpha/2$；单 $\alpha$"
  • "$t$ 区间半宽 = $t_{\alpha/2}(n-1)\cdot S/\sqrt n$"

六、真题套路 · 二级结论 · 速算技巧

选枢轴量速查

估计条件枢轴量
$\mu$$\sigma^2$ 已知$(\bar X-\mu)/(\sigma/\sqrt n)\sim N(0,1)$
$\mu$$\sigma^2$ 未知$(\bar X-\mu)/(S/\sqrt n)\sim t(n-1)$
$\sigma^2$$\mu$ 未知$(n-1)S^2/\sigma^2\sim\chi^2(n-1)$
$\sigma^2$$\mu$ 已知$\sum(X_i-\mu)^2/\sigma^2\sim\chi^2(n)$
$\mu_1-\mu_2$$\sigma$ 已知$\sim N$
$\mu_1-\mu_2$$\sigma$ 未知同方差合并方差 $S_w$，$\sim t(n_1+n_2-2)$
$\sigma_1^2/\sigma_2^2$—$\sim F(n_1-1, n_2-1)$

必背二级结论

  1. $\mu$ 区间（$\sigma$ 已知）：$\bar X\pm u_{\alpha/2}\sigma/\sqrt n$
  2. $\mu$ 区间（$\sigma$ 未知）：$\bar X\pm t_{\alpha/2}(n-1) S/\sqrt n$
  3. $\sigma^2$ 区间：$\left[\dfrac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)},\dfrac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right]$
  4. 双侧用 $\alpha/2$，单侧用 $\alpha$
  5. $\chi^2$ 区间不对称，上下分位数分开查
  6. $F$ 区间用倒数关系：$F_{1-\alpha/2}(m,n) = 1/F_{\alpha/2}(n,m)$
  7. 合并方差 $S_w^2 = \frac{(n_1-1)S_1^2+(n_2-1)S_2^2}{n_1+n_2-2}$
  8. 置信区间是随机区间，覆盖 $\theta$ 的概率 = $1-\alpha$

速算与解题技巧

  1. 选枢轴量按 "$\sigma$ 已知/未知" 分
  2. $\sigma$ 未知用 $t$，已知用 $u$
  3. 双侧 $\alpha/2$，单侧 $\alpha$
  4. $\chi^2$ 区间 "上下分位数对应大小数 / 反 corresponds 大方差 / 小方差"
  5. 大样本时 $t(n-1)\to N(0,1)$，可用 $u$ 近似（$n>30$）

常错"小坑"清单

  • 双 vs 单的分位数：$\alpha/2$ vs $\alpha$
  • $\chi^2$ 不对称，两个端点分别查
  • $\sigma$ 未知必须用 $t$，不能用 $u$
  • 合并方差自由度 $n_1+n_2-2$
  • "置信区间"是随机区间，不是说 $\theta$ 落入概率
