1.4 随机事件的独立性 ⭐

本节真题考频：14 套真题命中 7 套。选择题 1-2 题，常考"判断对错"和"两两 vs 相互独立"。
典型出题：判断 $A, B, C$ 相互独立的充要条件 · 串并联电路 · 100 人血清混合 · 独立事件至少一个发生。

一、两事件独立

⭐ 定义

事件 $A, B$ 独立 $\Leftrightarrow P(AB) = P(A)P(B)$

等价：若 $P(B) > 0$，$A, B$ 独立 $\Leftrightarrow P(A\mid B) = P(A)$（条件下不改变 $A$ 的概率）。

独立性传递到对立

若 $A, B$ 独立，则下列三组也独立：

$$\{A, \bar B\},\quad\{\bar A, B\},\quad\{\bar A, \bar B\}$$

证明（以 $\{A, \bar B\}$ 为例）：$P(A\bar B) = P(A)-P(AB) = P(A)-P(A)P(B) = P(A)(1-P(B)) = P(A)P(\bar B)$。

独立 vs 互斥（高频混淆点）：
  • 互斥：$AB = \varnothing$，即 $P(AB) = 0$
  • 独立：$P(AB) = P(A)P(B)$
  • 若 $0 < P(A), P(B) < 1$，两者不能同时成立（独立时 $P(AB) > 0$ 不互斥）

二、多事件独立

⭐ 三事件相互独立（注意有 4 个等式！）
$$P(AB) = P(A)P(B),\;P(AC) = P(A)P(C),\;P(BC) = P(B)P(C)$$ $$\text{且}\quad P(ABC) = P(A)P(B)P(C)$$

前 3 个 = 两两独立；加最后 1 个 = 相互独立。

"两两独立 ⇏ 相互独立！" 这是选择题常出陷阱。
反例 ★★（经典）：均匀掷一颗骰子。
  • $A$ = "1 或 2"，$B$ = "2 或 3"，$C$ = "1 或 3"
分析

每事件概率 1/3。$P(AB) = P(\{2\}) = 1/6 = (1/3)^2$，两两独立。

但 $ABC = \varnothing$（不存在同时属于三个的点），$P(ABC) = 0 \neq (1/3)^3 = 1/27$，不相互独立。

$n$ 事件相互独立的定义

$A_1, \ldots, A_n$ 相互独立 $\Leftrightarrow$ 对任意 $k\geq 2$ 个事件 $A_{i_1}, \ldots, A_{i_k}$：

$$P(A_{i_1}\cdots A_{i_k}) = \prod_{j=1}^k P(A_{i_j})$$

共需验证 $\binom{n}{2}+\binom{n}{3}+\cdots+\binom{n}{n} = 2^n-n-1$ 个等式。$n=3$ 时是 4 个，$n=4$ 时是 11 个。

三、独立事件的运算

⭐ 至少一个发生（独立时）

$A_1, \ldots, A_n$ 相互独立：

$$P\!\left(\bigcup_{i=1}^n A_i\right) = 1-\prod_{i=1}^n[1-P(A_i)]$$

同概率 $P(A_i) = p$ 时：$P = 1-(1-p)^n$

题 ★★（小概率不可忽视）：某地区慢性病每年发病率 0.004。今年 100 人血清混合检验。求至少一人患病的概率。
解
$$P = 1-(1-0.004)^{100}\approx 1-e^{-0.4}\approx 0.33$$

单次 0.4% 看似很小，100 次累积达 1/3。$n$ 大时小概率累积成大概率——临床检验、流行病学的核心。

题（电路通断）：四开关 $A_1, A_2, A_3, A_4$ 闭合概率均 $p$，独立。$A_1A_2$ 串联与 $A_3A_4$ 串联，两组并联。求电路通的概率。
解

串联通 = 两个都闭：$P_{\text{串}} = p^2$。

并联通 = 至少一组通：$P_{\text{并}} = 1-(1-p^2)^2 = 2p^2-p^4$。

题（更复杂电路）：$A_1$ 与 $A_2$ 串联，再与 $A_3$ 并联。$P(A_i) = p$ 独立。求通的概率。
解

串联通 $= p^2$，整体并联通 $= 1-(1-p^2)(1-p) = p^2+p-p^3$。

四、独立可传递到函数（重要！）

若 $A_1, \ldots, A_n$ 相互独立，则它们的任意子集函数也相互独立。

例如：$A_1\cup A_2$ 与 $A_3A_4$ 也独立（基于不同的索引集合）。

五、易错点清单

  • "两两独立 + 同概率 $p$ → 相互独立"——错！必须四个等式都验证
  • "互斥 + $0"——错，刚好相反
  • "独立的对立也独立"——这条容易忘，证明题常考
  • 串联看"全都闭"（$\prod$）；并联看"至少一个闭"（$1-\prod(1-)$）
  • 看到 "100 人每人 0.4% 患病"立刻用对立计算"至少一人患病" $= 1-(1-p)^n$
  • $P(A\cup B) = P(A)+P(B)-P(AB)$ —— 独立时简化但不要忘加法
记忆口诀：
  • "独立 ⇔ 乘积等于乘积"
  • "互斥 ⇔ 交集为空"
  • "对立 ⇔ 互斥 + 并为全集"
  • "独立 + 至少一个发生：$1-\prod(1-p_i)$"
  • "独立可传递到对立"

★ 历年真题原型（强化）

真题原型 1（18-19-1 · 红蓝网络攻防，独立性 + 全概率思路）：某系统遭三个独立黑客 $A_1,A_2,A_3$ 攻击，攻破概率分别 $0.3,0.4,0.5$，相互独立。求系统被攻破（至少一个攻破成功）的概率。
解

"至少一个"用对立 + 独立连乘：

$$P(\text{攻破}) = 1-\prod_{i=1}^3[1-P(A_i)] = 1-(0.7)(0.6)(0.5) = 1-0.21 = 0.79$$

关键：独立时"全不发生"概率 = 各自不发生概率之积，不能把 $0.3+0.4+0.5$ 简单相加（那会 $>1$ 且重复计交集）。

真题原型 2（23-24-2 题12 · 命题判断，独立性相关条目）：判下列 4 个命题正确个数。
  • ① 若 $A,B$ 独立，则 $\bar A,\bar B$ 也独立；
  • ② 若 $A,B$ 互斥且 $0
  • ③ 三事件两两独立 $\Rightarrow$ 相互独立；
  • ④ "恰有一个发生"的概率 $=P(A)+P(B)-2P(AB)$（两事件情形）。
解

① 对（独立传递到对立，本节二级结论 1）。

② 对：互斥 $\Rightarrow P(AB)=0$，而独立需 $P(AB)=P(A)P(B)>0$，矛盾。

③ 错：缺 $P(ABC)=P(A)P(B)P(C)$ 这第 4 个等式（本节骰子反例）。

④ 对：$A\bar B\cup\bar A B$ 互斥，概率 $=[P(A)-P(AB)]+[P(B)-P(AB)]=P(A)+P(B)-2P(AB)$。

正确 3 个（①②④）。逐条画 Venn 验证，别凭直觉。

★ 必背块（独立性核心）

⭐ 一定要默写出来的 5 条
  1. 两事件独立：$P(AB)=P(A)P(B)$；等价 $P(A\mid B)=P(A)$。
  2. 三事件相互独立 = 4 个等式：3 个两两 $+\ P(ABC)=P(A)P(B)P(C)$。$n$ 事件需 $2^n-n-1$ 个。
  3. 独立传递到对立：$\{A,\bar B\},\{\bar A,B\},\{\bar A,\bar B\}$ 同时独立。
  4. 至少一个发生（独立）：$P\!\left(\bigcup A_i\right)=1-\prod[1-P(A_i)]$；同概率 $=1-(1-p)^n$。
  5. 电路：串联通 $=\prod p_i$（全闭）；并联通 $=1-\prod(1-p_i)$（至少一闭）。
小概率累积（送命/送分）

$p$ 极小、$n$ 大：$1-(1-p)^n\approx 1-e^{-np}$（更准）或 $\approx np$（$np\ll1$ 时）。如 $p=0.004,n=100$：$1-e^{-0.4}\approx0.33$。

★ 易错点（强化 · 3 条）

  • ① 两两独立 ≠ 相互独立：选择题最爱的陷阱。三事件务必补验 $P(ABC)=P(A)P(B)P(C)$，缺这一条就只是两两独立（骰子 $A$=1或2、$B$=2或3、$C$=1或3 是经典反例：两两独立但 $P(ABC)=0\ne1/27$）。
  • ② 互斥 ⇎ 独立（恰好相反）：$00$，二者不可兼得。看到"互斥就当独立用"立即停。
  • ③ "至少一个"别直接加：$P(\bigcup A_i)\ne\sum P(A_i)$（会重复计交集，且可能 $>1$）。独立时一律走对立 $1-\prod(1-P(A_i))$；不独立用容斥。

六、真题套路 · 二级结论 · 速算技巧

判独立题型

  • 两事件：验 $P(AB) = P(A)P(B)$
  • 三事件相互独立：验 4 个等式（含 $P(ABC) = P(A)P(B)P(C)$）
  • $n$ 事件相互独立：验 $2^n-n-1$ 个等式

必背二级结论

  1. 独立传递到对立：$\{A,B\}, \{A,\bar B\}, \{\bar A,B\}, \{\bar A,\bar B\}$ 同时独立或同时不独立
  2. 独立 + 至少一个发生：$P(\bigcup A_i) = 1-\prod(1-P(A_i))$
  3. 同概率独立 $n$ 事件：$P(\bigcup A_i) = 1-(1-p)^n$
  4. 独立 ⇏ 互斥（除 $P=0$ 或 $1$）
  5. 互斥 + $0
  6. 两两独立 ⇏ 相互独立（缺 $P(ABC) = $ 乘积条件）
  7. 独立 ⇒ 条件概率不变：$P(A\mid B) = P(A)$
  8. $n$ 重 Bernoulli：$n$ 次独立 + 同 $p$ 试验

速算与解题技巧

  1. 电路通断：串联通 = 所有通（$\prod p$）；并联通 = 至少一通（$1-\prod(1-p)$）
  2. 小概率 $n$ 重叠加：$1-(1-p)^n\approx np$（$p$ 极小，泰勒展开）或 $\approx 1-e^{-np}$（$n$ 大）
  3. 判独立先看物理意义：常识上是否相互影响
  4. $P(A\mid B) = P(A)$ 反推独立：若条件不变就是独立

常错"小坑"清单

  • 两两独立 → 相互独立（错）：必须验 $P(ABC) = P(A)P(B)P(C)$
  • 独立可传递到对立：常被忘记
  • 互斥 + 独立：$0
  • 电路题分串并联：搞清结构图再算
  • 大数 $n$ 时小概率累积：100 人 0.4% 的累积概率 0.33，不是小数
