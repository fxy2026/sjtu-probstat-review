💎 二、30 条必背二级结论

第 1 章

  1. De Morgan：$\overline{A\cup B}=\bar A\bar B,\,\overline{AB}=\bar A\cup\bar B$
  2. 三事件容斥带 $+P(ABC)$
  3. "至少一个发生"用对立 $1-\prod(1-P)$ 更简单
  4. 独立 ⇏ 互斥（$0
  5. 两两独立 ⇏ 相互独立（需四个等式）
  6. Bayes 公式分母必须展开成全概率

第 2 章

  1. 分布函数右连续，跳跃高度 = 该点概率
  2. $B(n,p)$ 最可能值 $k^*=\lfloor(n+1)p\rfloor$
  3. Poisson 适用：$n\geq 20,p\leq 0.05$
  4. $E(\lambda)$ 无记忆性：$P(X>s+t\mid X>s)=P(X>t)$
  5. 正态标准化分母用 $\sigma$ 不是 $\sigma^2$
  6. $\Phi(-x)=1-\Phi(x)$
  7. $X\sim N(0,1)\Rightarrow X^2\sim\chi^2(1)$，密度 $\dfrac{1}{\sqrt{2\pi y}}e^{-y/2}$

第 3 章

  1. 边缘分布不能唯一决定联合分布
  2. 可分离 + 矩形支撑 ⇔ 独立
  3. 二维正态独立 ⇔ $\rho=0$（仅此分布）
  4. 二维正态条件方差缩 $(1-\rho^2)$
  5. 独立可加性需同 $p$（二项）或同分布族（正态/Poisson/卡方）
  6. $n$ 个独立 $E(\lambda)$ min $\sim E(n\lambda)$
  7. $X,Y\sim N(0,1)$ 独立 $\Rightarrow X^2+Y^2\sim E(1/2)=\chi^2(2)$

第 4 章

  1. $E(X+Y)=E(X)+E(Y)$ 无需独立，但 $E(XY)=E(X)E(Y)$ 需要
  2. 示性函数：$E(I_A)=P(A)$（计数期望神器）
  3. $D(X\pm Y)=D(X)+D(Y)\pm 2\Cov$（同号！）
  4. 独立 $\Rightarrow$ 不相关，反之仅在二维正态成立
  5. $|\rho|=1$ ⇔ 线性关系 a.s.

第 5 章

  1. Chebyshev 给"下界"，与 CLT "精确"对比
  2. CLT 标准化：$Z=\dfrac{\sum X_i-n\mu}{\sqrt n\sigma}$（$\sqrt n$ 不是 $n$）

第 6-8 章

  1. $\dfrac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$，$\bar X$ 与 $S^2$ 独立
  2. $\sigma$ 未知用 $t(n-1)$，已知用 $N(0,1)$
  3. $F$ 倒数关系：$F_{1-\alpha}(m,n)=1/F_\alpha(n,m)$

⚠️ 三、致命易错清单（每年都有人栽）

⚠️ 概率部分
  • "不都发生"≠"都不发生"（$\overline{ABC}$ vs $\bar A\bar B\bar C$）
  • 差事件 $A-B$ 不要求 $B\subset A$
  • Bayes 分母直接写 $P(A)$ 没展开 → 扣过程分
  • 古典概型必须等可能
⚠️ 一维 / 二维分布
  • 分布函数右连续，$P(X
  • 连续型 $P(X=a)=0$ 但不表示事件不可能
  • 函数分布忘记分段（$Y=X^2$ 必须 $y>0$）
  • 正态标准化分母用 $\sigma$，$\Phi(-x)=1-\Phi(x)$ 漏减号
  • 看到可拆形式 $r(x)g(y)$ 立刻判独立 → 必须先看支撑是否矩形！
⚠️ 数字特征
  • $D(X-Y)$ 独立时 = $D(X)+D(Y)$（同号！）
  • $E(XY)=E(X)E(Y)$ 乱套（未确认独立）
  • 不相关 ≠ 独立（除非二维正态）
  • $\Cov$ 双线性符号搞反
⚠️ 极限定理
  • CLT 分母 $\sqrt n\sigma$（不是 $n\sigma$，不是 $\sqrt n\sigma^2$）
  • $\bar X$ 方差 = $\sigma^2/n$（除以 $n$ 不是 $\sqrt n$）
  • Chebyshev 估计有时给出 $\leq 0$，无意义
⚠️ 统计 / 估计 / 检验
  • $\chi^2$ 与 $S^2$ 关联自由度是 $n-1$（用 $\bar X$ 代替 $\mu$）；$\mu$ 已知是 $n$
  • $t$ 分布分子分母必须独立
  • $F$ 倒数 / 分位数对偶混淆
  • $\hat\sigma^2_{MLE}=S_n^2$（$n$）≠ $S^2$（$n-1$）
  • $\chi^2$ 区间 / 双侧检验不对称，上下分位数不同
  • $\sigma$ 未知 → $t$ 不要错用 $u$
  • 单侧 vs 双侧分位数：$\alpha$ vs $\alpha/2$
  • 边界型 MLE（如 $U(0,\theta)$）求导失效，看单调性

🎲 四、答题速算技巧

组合恒等式：
  • $\sum_{k=0}^n C_n^k=2^n$
  • $C_n^k=C_n^{n-k}$
  • $kC_n^k=nC_{n-1}^{k-1}$
积分技巧：
  • $\int_0^\infty x^n e^{-x}\dd x=n!$
  • $\int_{-\infty}^\infty e^{-x^2/2}\dd x=\sqrt{2\pi}$
  • 正态 $\int_{-\infty}^\infty xe^{-(x-\mu)^2/(2\sigma^2)}\dd x=\sqrt{2\pi}\sigma\cdot\mu$
  • 分部积分对指数+多项式：$\int x e^{-\lambda x}\dd x=-\frac{x+1/\lambda}{\lambda}e^{-\lambda x}+C$
常用极限：
  • $\left(1-\frac{x}{n}\right)^n\to e^{-x}$
  • $\binom{n}{k}\sim n^k/k!$（$n$ 大）
  • Stirling：$n!\sim\sqrt{2\pi n}(n/e)^n$

📌 五、最后 30 分钟看这些

1. 全概率 / Bayes 模板
"设事件 $B_i$ 表示 $\ldots$（验证划分），则 $P(A)=\sum P(B_i)P(A\mid B_i)=\ldots$；后验 $P(B_i\mid A)=\dfrac{P(B_i)P(A\mid B_i)}{P(A)}=\ldots$"
2. CLT 模板
"$X_i$ i.i.d.，$E(X_i)=\ldots$，$D(X_i)=\ldots$，由 CLT，$\sum X_i\approx N(n\mu,n\sigma^2)$；标准化 $Z=(S-n\mu)/(\sqrt n\sigma)\approx N(0,1)$，所求 $P(\ldots)=\Phi(\ldots)-\Phi(\ldots)=\ldots$"
3. MLE 模板
"似然 $L(\theta)=\prod f(X_i;\theta)=\ldots$；对数 $\ell=\ln L=\ldots$；$\dfrac{d\ell}{d\theta}=0\Rightarrow\hat\theta=\ldots$；验证二阶导<0。"
4. 假设检验模板
"① $H_0:\theta=\theta_0$ vs $H_1:\ldots$；② 统计量 $T=\ldots\sim\ldots$；③ 拒绝域 $\{|T|>\ldots\}$；④ 计算 $T_{\text{obs}}=\ldots$；⑤ $T_{\text{obs}}$ ∈/∉ 拒绝域 → 拒绝 / 接受 $H_0$。"
5. 抽样分布构造模板
"$X_i$ i.i.d. $\sim N(0,\sigma^2)$。线性组合 $aX_1+bX_2\sim N(0,(a^2+b^2)\sigma^2)$ 标准化平方 $\sim\chi^2(1)$；多个组合相加 $\sim\chi^2(k)$。"
